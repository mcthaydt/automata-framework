# Free base-3d quality pass: review images (2026-10-31)

From the built page (Chromium, SwiftShader, 844 × 390), throwaway builds that move the spawn; compare with the first pass in
`../2026-10-31-free-base-3d/` and with Emberwick's screens.

- `room-start.png`: the first platform: lighter floors against darker walls, embers turning and pulsing.
- `room-channel.png`: Wick short of the first channel: a bright lip marks each edge and the channel is dark lava below, so the
  place to roll from reads at a glance.
- `room-goal.png`: the goal platform from the higher framing: the goal ember is larger and gold with a beam over it, visible even
  with Wick beside it.

Sounds are audible only in a browser with audio; they are the four generated cues in `games/base-3d/public/sounds/`.
