# Direction log

The Owner's direction for AF, moved here unchanged from `AGENTS.md` on 2026-11-05 (refactor task 7.1). Read it for the history of a decision; `AGENTS.md` holds the rules that apply now.

**Current direction (Owner, 2026-10-11):** AF is **Ruken first**. Core packages are built from proven code in FloorFifty (2D), The Last Light (`PixiJS3D_Experiment_001`, 3D) and Ruken; everything else is an opt-in extension. PixiJS renders 2D and 3D (ADR 0002). Effect runs everything outside the sim; the sim stays on Koota and never imports Effect (ADRs 0001, 0003). Ruken's packages and process are the foundation (ADR 0004). CI/CD, deployment, mobile UI and the content compiler come first, in M1. AF 1.0 covers 2D and 3D, and the 3D runtime is free, not Plus (2.5D was dropped on 2026-10-18; **Owner, 2026-10-23: "3D ships 1.0"**, M3R-D10, M3R-D20): the base 3D game, `games/base-3d`, is built on AF inside 1.0 and its proven 3D systems become packages (M9) before the launch. Run CI locally (Node 24, Playwright browsers, all jobs including parity): hosted Actions jobs are not getting runners. Each milestone's spec is reviewed before its task plans; in M1, work runs in parallel lanes (`docs/archive/04-how-we-build.md`), each writing its task spec first and getting it reviewed in its own PR. Decisions D-1 to D-6 run on their recommended defaults (master spec §12). Preserve the merged M0 work. **Owner, 2026-10-16:** loosen the Ruken coupling so a game publishes to Ruken or itch.io: Ruken stays the reference host and contract vocabulary, the target is chosen at build time, and itch.io is a supported target ([ADR 0005](docs/adr/0005-publish-targets.md), PUB spec; approved 2026-10-16). **Owner, 2026-10-16:** DX.0, PRODUCT.0, EX.0, QB.0 and PUB.0 are approved with every recommended default. **Owner, 2026-10-18:** drop 2.5D. **Owner, 2026-10-23:** "procedural only for now": rigged glTF characters are deferred (procedural figures with an IK rig for posing and animation), the 3D camera is Crow Country's angle on a 24 mm lens, 25° down and 5 m back, turned freely by the player; the Ocarina-style action-adventure is the base 3D game, the counterpart of Emberwick, with "everything we did for 2D" done for 3D, matching the 2D game's quality and authored in the editors; **the AF 1.0 launch waits for Pixi 3D's public release** (Owner, 2026-10-23: "we launch when pixi 3D goes public"; `@pixi/3d` is a closed beta, so we build on it with private builds meanwhile, M3R-D18) ([revised M3 spec](docs/archive/superpowers/specs/2026-10-18-m3-3d-characters-design.md), approved by the Owner 2026-10-23). **Owner, 2026-10-30:** finish everything through the AF 1.0 launch, the website included; Pixi 3D goes public in about two weeks, so plan to completion on the vendored `@pixi/3d` 0.1.0-beta.2 (copied from The Last Light, swapped for the npm release when it ships); the agent may merge its own PRs once every check, parity included, is green on the head; there is no orchestrator or bus any more, so questions, device-test requests and acceptances go to the Owner directly; FigureBuilder (`mcthaydt/FigureBuilder`) is the procedural character source alongside The Last Light.
