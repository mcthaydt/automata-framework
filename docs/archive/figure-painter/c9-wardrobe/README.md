# The figure painter's wardrobe cycle (c9), as a record

The spec, the plan and the plan audit of the wardrobe cycle of the figure painter, copied unchanged from the retired
repository `mcthaydt/FigureBuilder` (archived, read only) at commit `856498a`, the tip of its branch
`claude/c9-wardrobe`. The painter's code for the cycle's first six tasks (F0 to F6: sheer cloth, the shod foot, the head's
form, front hair, hair that rests on the trunk, a fringe) came across as commits in
[the fold's merge](../../../superpowers/plans/2026-11-12-builders-fold.md); the remaining tasks continue in the framework,
and this plan is their step-level text.

The Checkpoint A sheets of that cycle (five PNGs, 5.1 MB, `docs/superpowers/audits/2026-11-11-c9-checkpoint-a/` in the
retired repository) are evidence, not record: they stay there. Links inside these three documents point at paths of
that repository and are not checked here.
