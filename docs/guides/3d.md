# Make a 3D game

> **3D is in beta.** Pixi 3D is public on npm, and a 3D game publishes to every host a 2D one does. `@automata/3d` is not
> published yet, so outside this repository `automata create-game --template 3d` stops and says so unless `AF_BETA_3D=1`
> is set and you have the package. Leave out `--template` to make a 2D game.

A 3D game is made the same way as a 2D one: rules in the sim, words and levels in `content/`, and a small app that puts
them together. What changes is what you draw with and what a level is.

## Start one

```sh
pnpm exec automata create-game my-game --template 3d
cd my-game
pnpm install
pnpm dev
```

You get Wick, a small figure, walking around one room. Move with W, A, S and D or the arrow keys, and turn the camera
with Q and E. On a touch screen the stick walks and dragging the screen turns the camera. On a gamepad the left stick
walks and the right stick turns.

## What is in the folder

| File | What it is for |
|---|---|
| `content/levels/room.af-sector.json` | The room: its floor, walls, props and where Wick starts |
| `content/figures/wick.toml` | Wick himself: his body, his clothes and how he walks |
| `content/tuning.toml` | How fast Wick walks, in numbers the Tuner can slide |
| `src/features/wick/` | The rules for Wick: what he holds, what the player asks, what runs each tick |
| `src/features/room/` | How the game reads the room: the floor Wick stands on and what he cannot walk through |
| `src/app/game.ts` | Where the game is put together: the controls, the screen size, the camera |

Each thing in your game gets its own folder under `src/features/`, as in a 2D game. The rules are still plain
TypeScript that never reads the clock or `Math.random`, so the same start and the same inputs give the same hash on
every browser.

## Change the room and the figure

```sh
pnpm exec automata editor
```

Open the address it prints. The room opens in the 3D level editor, Wick opens in the character editor and the walk
speed opens in the Tuner. Press Save and the game plays the new version. The [editor guide](./editor.md) has the rest.

## Draw only the rooms a camera sees

A level with many rooms need not draw them all. A camera view in the level's `views` can name the rooms it shows:

```json
"views": { "ward": { "rooms": ["ward", "bay"] }, "hall": {} }
```

A view with no `rooms` draws every room, as before. The Levels 3D editor lists a room's camera under Camera and lets you
tick its rooms; none ticked draws every room. A view that names a room the level does not have is a problem in words,
not a crash.

Four things are drawn whatever the view says. The game turns them on by returning `roomHooks` from its scene hook, beside
`drawWorld`, with the camera the hook is given:

- the room the player stands in;
- the room just left, for 0.35 seconds, so a cut does not pop it out from under the camera's blend;
- the room on the far side of a doorway the player is peeking through;
- every room, while a cutscene plays.

Lamps come in `pendant`, `bulb`, `desk`, `fluorescent`, `sodium` and `neon`, and now `moon` (a cool, soft light through a
window) and `fill` (a soft light with no fitting and no glow). The kit also covers a reference game's lamps: `fire`, `gas`, `screen` and
`spark`, and bands wide enough for its pendant (up to 9 m) and its moon and fill (the old moon and fill are a coloured `neon` at their own
colour). Every kind is a steady light: a flame or a spark that flickers is the game's to drive through the lamp's `level`.

## Check it

```sh
pnpm test      # the tests of the rules
pnpm check     # everything the game has to pass before it is published
```

`pnpm check` reads the sim for anything that would break the same-hash promise, compiles `content/` and runs the tests.

## Publishing

A 3D game is published the way a 2D one is. The one thing every host refuses is Pixi 3D's extras
(`@pixi/3d/extras`): its particle code needs `eval`, which no host's security policy allows, so import only
`@pixi/3d` itself. The guides for each host: [web](./publish-to-web.md), [itch.io](./publish-to-itch.md),
[desktop](./publish-to-desktop.md) and [Ruken](./publish-to-ruken.md).
