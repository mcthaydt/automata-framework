## What is wrong

A new high advisory, GHSA-mrhx-c7xc-m3w5 ("Zod can exhaust memory while validating oversized constrained collections", vulnerable `<4.6.6`, patched `>=4.6.6`), makes `pnpm audit --prod --audit-level=high` exit 1. The workspace pins `zod` `4.6.5` in 23 `package.json` files (the hub counted 14; it also pins it in `games/emberwick`, the `examples` packages and the tooling packages). The vendored `@ruken/cli` and `@ruken/sdk-host` tarballs declare `zod` 4.6.5 exactly in their own manifests, so the audit's path `tooling/examples-runner > @ruken/sdk-host > zod` stays red after the pins move.

## Decisions

- **4.6.6, the first patched version**, the smallest step. Ruken's `docs/versions.md` also pins 4.6.5 (checked at `bc469b8`); the hub moves Ruken to 4.6.6 at the same time, so AF's "Same as Ruken" row stays true.
- **Everything that names the version moves with the pins**, as in the `vite` 8.3.3 bump (#96): the 23 manifests, `pnpm-lock.yaml`, `packages/cli/src/create-game.ts` (a new game's `zod`), `tooling/consumer-smoke/src/project.test.ts` (its fixture), `docs/versions.md`, `docs/stack.md` (generated: `pnpm docs:stack`), and the vendor label in `packages/cli/src/check/no-eval-allowlist.ts`. Not changed: the `tooling/versions` tests' fixtures (a made-up page) and old plans, specs and ADR 0003 (history).
- **A pnpm override for the vendored tarballs**, `overrides: { zod: 4.6.6 }` in `pnpm-workspace.yaml` with a comment, because AF's vendoring rule is that lanes do not repack `vendor/ruken/` and only Ruken's repack can move the tarballs' own manifests. Drop it when they are repacked from a Ruken that pins 4.6.6 (a note in `vendor/ruken/README.md`).
- **One patch changeset** for the seven published packages whose manifest changes (`check-boundaries`, `content`, `host`, `physics`, `ship`, `sim`, `testing`); the private ones need none.
- **The no-eval allowlist stays as it is**, checked against the 4.6.6 bundle instead of assumed: `automata check games/emberwick --csp` (build, scan, real-browser CSP probe) must pass.
