## DIST.5a

### Interfaces

- **Produces** `@mcthaydt/automata-host/target` under `automata-tauri`: `makeHosting`, `HostingLive` (the same
  signatures as the other adapters). Internally `makeTauriHosting(options, page, desktop)` over a `DesktopPort`:
  `loadStore(): Promise<StoreLike>`, `onCloseRequested(handler): Promise<() => void>`, `exitApp(): Promise<void>`;
  `tauriDesktop()` is the real port (`@tauri-apps/plugin-store` `load('saves.json')`, `@tauri-apps/api/window`
  `getCurrentWindow().onCloseRequested`, `@tauri-apps/plugin-process` `exit(0)`).
- **Produces** `TAURI_MARKERS` and `findTauriMarkers` beside the Ruken markers.
- **Changes** `ui`'s boot failure: with `hostKind: 'tauri'` and `exit` granted, the exit action reads "Quit".
- **Behavior (spec §4.3, §6.1):** the web adapter's lifecycle, input, display, audio and fullscreen; `kind: 'tauri'`;
  `hostName` is the page's `<title>`; `saves` in the store (granted only when it loads; otherwise every call fails
  `DENIED` and nothing is written anywhere; a failed write fails `INTERNAL`, retryable); `flush` saves the store and
  answers `device`; `exit` and the window's close request run the `onExiting` handlers in order, then the flush, within
  `HOST_EXIT_CAP`, then quit.

### Steps

1. [ ] **Contract on the adapter.** `hosting-tauri.test.ts` runs `describeHostingContract` on `makeTauriHosting` over a
   fake page and a fake desktop port. Red: no module. Green: the adapter.
2. [ ] **Pinned differences** (each red first): kind and `hostName` from the page title; `exit` granted; saves in the
   store, not `localStorage` (a spy on the page's storage sees nothing); a store that fails to load: `saves` not granted,
   every call `DENIED`, store and page storage untouched; a failed write `INTERNAL` and retryable; `flush` saves the
   store and answers `device`; `exit` and a close request run handlers, then the flush, then quit, within the cap
   (`TestClock`), and the close request is held until then.
3. [ ] **The real port.** `desktop-tauri.test.ts` (jsdom) with `mockIPC`: load, get, set, delete, keys, save and exit
   reach the plugins' commands; a close request reaches the handler.
4. [ ] **Build condition and markers.** `target.build.test.ts`: an `automata-tauri` build holds the Tauri adapter and
   `TAURI_MARKERS`, no Ruken marker; web and Ruken builds hold no Tauri marker. Red, then the `exports` and tsdown entry.
5. [ ] **"Quit".** A DOM test: the boot failure on `hostKind: 'tauri'` with `canExit` shows "Quit"; on Ruken "Back to
   Ruken". Red, then the copy.
6. [ ] Changeset, versions rows, API outputs; gates; one push; draft PR stacked on #334.
