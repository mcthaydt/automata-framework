# M1.6: Mobile-first UI primitives, TDD plan

**Goal:** build `@mcthaydt/automata-ui` and the layout/fixture half of `@mcthaydt/automata-testing` per the [M1.6 spec](../specs/2026-10-11-m1-ui-design.md).

**Spec:** `docs/superpowers/specs/2026-10-11-m1-ui-design.md` (§ numbers below refer to it).

**Progress:** 15 of 15 tasks implemented and locally checked; CI verified, reviewed and Owner accepted are still open.

**Tech:** Node 24.21.0, pnpm 10.33.4, Svelte 5.57.1, `@sveltejs/vite-plugin-svelte` 7.3.1, svelte-check 4.7.6 + TypeScript 6.0.3 (ui only), Vitest 5.0.3 (+ browser-playwright, Playwright 1.63.0), jsdom 30.1.1, Testing Library (svelte 5.4.2, dom 10.4.2, jest-dom 7.0.1, user-event 14.6.7), `@ruken/sdk` (vendored, types). Nano Stores was dropped on 2026-10-11 for Svelte 5 rune stores (master spec §3).

**Commands**

| Name | Command |
|---|---|
| ui unit (focused) | `pnpm --filter @mcthaydt/automata-ui exec vitest run --project unit <file>` |
| ui layout (focused) | `pnpm --filter @mcthaydt/automata-ui exec vitest run --project layout <file>` |
| testing unit | `pnpm --filter @mcthaydt/automata-testing exec vitest run --project unit` |
| full gate | `pnpm check`, then `pnpm --filter @mcthaydt/automata-ui test:layout`, `pnpm --filter @mcthaydt/automata-testing test:layout`, `pnpm --filter @mcthaydt/automata-sim exec vitest run --project browsers` |

Notes: `svelte-check` warned "no svelte input files" until Task 6 added the first component, so `pnpm typecheck` was red only for that reason between Tasks 1 and 6.

Every task: write the test, run it and see it fail for the stated reason, write the least code, run it green, `pnpm format`, commit with the tick.
