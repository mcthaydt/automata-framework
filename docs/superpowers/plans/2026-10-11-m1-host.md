# M1.4 Host: implementation plan

> Steps use checkboxes. Tick each one when its check passes and commit the tick with that step's work.

**Goal:** Build `@mcthaydt/automata-host` as the [M1.4 host spec](../specs/2026-10-11-m1-host-design.md) and the [M1 shared contracts](../specs/2026-10-11-m1-shared-contracts-design.md) §1 describe:
- `Hosting` on `Ruken.init`, with one layer, `HostingLive`;
- `HostError` and `HostHandshakeFailed`;
- `./testing` (`HostingTest` and `manualClock`);
- the ported FloorFifty and S6 tests.

**Progress:** 9 of 9 tasks, locally checked. Review, hosted CI and Owner acceptance are still pending.

**Tech stack:** Node 24, pnpm 10.33.4, TypeScript 7.0.2 (`isolatedDeclarations`), Vitest 5.0.3 and Biome 2.5.15, all from the root config. This package adds:
- `effect` 3.22.2, the repo-wide choice (Deviations);
- `@ruken/sdk` and `@ruken/sdk-host`, from the integration owner's `vendor/ruken/` (RukenApp `b30d31b`).

**Consumed interfaces:**
- `@ruken/sdk`: `Ruken.init`, `RukenSession`, `RukenError`, `SdkEnv`, `SdkMessagePort`, `StorageLike` and the re-exported protocol types.
- `@ruken/sdk-host/testing`: `createFakeHost`, `FakeHost`, `FakeHostOptions` and `settle`.

**Produced interfaces:** spec §3 and shared contracts §1.

## Deviations
- `effect` 3.22.2: the coordinator chose it repo-wide on 2026-10-11, because Effect 4.0.0 was then only ten days old.
- The design moved mid-task (2026-10-11), as the coordinator relayed from the integration owner:
  - `CapabilityDenied` and `HostRequestFailed` became one `HostError`;
  - the separate web adapter and its browser fullscreen, links and visibility code were dropped (the SDK's standalone session is the web path);
  - a failed in-frame handshake falls back to standalone and is reported, where it was first going to be fatal;
  - ads, links and `hostReserved` left core.
- Not built: the `RecordingHosting` from the first draft. Screen tests can use `HostingTest`, which runs the real protocol.
- The menu-before-ready guard is new AF behaviour, by coordinator decision. It is recorded in shared contracts §1.6.
