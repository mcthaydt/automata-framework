# A1a: Sim Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `@mcthaydt/automata-sim`, the deterministic simulation core, together with the `check-boundaries` and `check-style` tools and a CI workflow that enforces them across Node, Chromium, WebKit and Firefox.

**Architecture:** A pure TypeScript package with no DOM, no clock and no I/O.
- **Building blocks** (bit-exact everywhere, each with its own tests): deterministic math, XXH64, canonical JSON, and an xoshiro128** RNG.
- **The sim:** game code defines components, commands, events, resources and systems, and groups them into plugins. `createSim` orders the systems and runs them over an `EntityStore`. The store owns StableIds, iteration order and render change-tracking; Koota only stores the data.
- **Snapshot v1:** a canonical binary format. Its XXH64 is `sim.hash()`.
- **Enforcement:** two AST-based checkers keep the determinism rules and naming rules true as the codebase grows.

## Global Constraints

- **The seven laws** (overview spec §2). In `packages/sim`, this means no I/O, no wall clock, no `Math.random`, and no host globals.
- **Determinism is cross-engine.** Every `*.parity.test.ts` asserts one committed hash in Node, Chromium, WebKit and Firefox. Never set a different expected value per engine, and never treat a mismatch as flaky.
- **`packages/sim` rules** (spec §3.3 and §11; enforced from Task 11):
  - `Math` is limited to `sqrt fround round floor ceil trunc abs min max sign imul`; use `./math` for everything else.
  - No `**` or `**=` operators.
  - No `Object.keys/values/entries`, `Reflect.ownKeys` or `for…in`. Use `sortedKeys`/`sortedEntries`; only `util/sorted.ts` is exempt.
  - Imports only from `koota`, `zod`, the Rapier deterministic-compat builds, or relative paths.
- **Biome:** `style/useExponentiationOperator` is **off** for `packages/sim/**`. Its auto-fix rewrites `Math.pow` into `**` (A0 final review).
- **Naming** (spec §3.3, enforced from Task 12): kebab-case file names. `define*` results live in a file with the matching role suffix (`*.component.ts`, `*.system.ts`, `*.command.ts`, `*.event.ts`, `*.resource.ts`, `*.plugin.ts`). `testing/` folders and tests are exempt.
- **TypeScript:** `packages/sim` uses `lib: ["ES2023"]` only, so DOM and Web APIs fail to typecheck. Exported declarations need explicit types (`isolatedDeclarations`).
- **Process:**
  - Strict TDD: every step pair is test-first, then implementation.
  - Run `pnpm format` before every commit; the pre-commit hook rejects unformatted files.
  - Conventional Commits, each ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Packaging (until plan 2c):** package `exports` point at `src/*.ts` (workspace-internal). Builds, Changesets and publishing to `@mcthaydt/*` on GitHub Packages come in plan 2c.
- **Commands** (always from the repo root):
  - Run one package's tests: `pnpm --filter <pkg> exec vitest run [--project node|browsers] [path-filter]`.
  - Run everything: `pnpm check`.

## Design Decisions (where this plan is more specific than the spec)

The final-review step checks each of these as a ruling:

1. **Render delta (spec §4.7).** The store does its **own dirty tracking**, as §4.7 permits; it does not use Koota `Changed`, which S1 showed is easily silenced.
   - `changed` rows carry the entity's **full** render state, so a removed component shows up as its absence.
   - `RenderDelta.resync` marks a full resync: the first step of a fresh sim, and the first step after `restore()`.
2. **`StepResult.rejected`.** Spec §4.4 rule 4 says invalid commands are "rejected and logged". The sim has no I/O, so it *returns* them with a reason: `bad-header | unknown-command | wrong-tick | duplicate-seq | invalid-payload`.
3. **Finite fields.** f32/f64 fields reject NaN and ±Infinity, because NaN's byte pattern is engine-chosen and would break canonical snapshots. `entity` is a u32 StableId, with 0 meaning none.
4. **`EntityRef.get()` returns a frozen copy.** Mutating it throws; writes go through `set`.
5. **Built-in systems** are wired by implicit constraints. Every `input` system runs after `commands.apply`. Every `cleanup` system runs before `entities.flush`, which runs before `render.collect`.
6. **Out of scope here:**
   - Koota relations: none in snapshot v1; section 5 is reserved for the first gameplay system that needs them.
   - Physics: section 6, plan 2b.
7. **Host-side setup.** `sim.spawn/entity/query/resource` exist for scene setup and inspection outside `step`. Runtime changes must go through commands, or replays diverge.

## Review Focus

The five failure modes most likely to bite someone writing a game on this, and where each is pinned:

1. **`e.get(Position).x += 1` silently does nothing**, because it mutates a copy. Pinned: `get()` returns a frozen object and the write throws a TypeError (Task 7).
2. **A system leaves a resource outside its schema** (wrong type, missing field), and the problem only surfaces much later. Pinned: `snapshot()` throws, naming the resource (Task 9).
3. **Restoring a corrupt or foreign snapshot half-applies it.** Pinned: `restore` validates everything before swapping state. Format errors and schema/content/tickHz mismatches leave the sim untouched and usable (Task 9).
4. **Adding a new system shifts every other system's random numbers**, which breaks replays and goldens. Pinned: per-system RNG substreams are seeded from the system name (Task 8).
5. **Iteration order leaks into results.** Pinned:
   - queries are in ascending StableId order;
   - StableIds are never reused;
   - an order-dependent fixture (fold + RNG-chosen despawns) must match across engines and across restore (Tasks 7 and 9).

```ts
// The only place in packages/sim allowed to enumerate object keys (check-boundaries exempts this file).
// Engines enumerate integer-like keys first and insertion order otherwise; sorting removes that dependency.

/** Own enumerable string keys, sorted by UTF-16 code unit. */
export function sortedKeys(obj: object): string[] {
  return Object.keys(obj).sort()
}

/** Own enumerable [key, value] pairs, sorted by key. */
export function sortedEntries<V>(obj: Readonly<Record<string, V>>): Array<[string, V]> {
  return sortedKeys(obj).map((k) => [k, obj[k] as V])
}
```

```ts
import { expect, test } from 'vitest'
import { atan, atan2, cos, exp, log, pow, sin, tan } from './dmath'

// Deterministic PRNG for sampling (mulberry32: 32-bit integer ops only).
function sampler(seed: number): () => number {
  let a = seed >>> 0
  return () => {
    a = (a + 0x6d2b79f5) >>> 0
    let t = a
    t = Math.imul(t ^ (t >>> 15), t | 1)
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61)
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296
  }
}

function maxErr(f: (r: () => number) => [number, number], rel = false): number {
  const rand = sampler(7)
  let worst = 0
  for (let i = 0; i < 100_000; i++) {
    const [got, want] = f(rand)
    const e = rel ? Math.abs((got - want) / want) : Math.abs(got - want)
    if (e > worst) worst = e
  }
  return worst
}

test('stays within ~1 ulp of the built-ins (pow within 1e-12)', () => {
  expect(
    maxErr((q) => {
      const x = q() * 2000 - 1000
      return [sin(x), Math.sin(x)]
    }),
  ).toBeLessThan(1e-14)
  expect(
    maxErr((q) => {
      const x = q() * 2000 - 1000
      return [cos(x), Math.cos(x)]
```

```ts
// XXH64 in pure TypeScript (BigInt). No wasm, no platform hashing: identical in every engine.
// Reference: https://github.com/Cyan4973/xxHash/blob/dev/doc/xxhash_spec.md

const MASK = 0xffffffffffffffffn
const P1 = 0x9e3779b185ebca87n
const P2 = 0xc2b2ae3d27d4eb4fn
const P3 = 0x165667b19e3779f9n
const P4 = 0x85ebca77c2b2ae63n
const P5 = 0x27d4eb2f165667c5n

const rotl = (x: bigint, r: bigint): bigint => ((x << r) | (x >> (64n - r))) & MASK
const round = (acc: bigint, input: bigint): bigint => (rotl((acc + input * P2) & MASK, 31n) * P1) & MASK
const merge = (acc: bigint, val: bigint): bigint => (((acc ^ round(0n, val)) * P1) & MASK) + P4

/** XXH64 of `data` with an unsigned 64-bit `seed`. */
export function xxhash64(data: Uint8Array, seed = 0n): bigint {
  const view = new DataView(data.buffer, data.byteOffset, data.byteLength)
  const len = data.byteLength
  let p = 0
  let h: bigint
  if (len >= 32) {
    let v1 = (seed + P1 + P2) & MASK
    let v2 = (seed + P2) & MASK
    let v3 = seed & MASK
    let v4 = (seed - P1) & MASK
    for (; p + 32 <= len; p += 32) {
      v1 = round(v1, view.getBigUint64(p, true))
      v2 = round(v2, view.getBigUint64(p + 8, true))
      v3 = round(v3, view.getBigUint64(p + 16, true))
      v4 = round(v4, view.getBigUint64(p + 24, true))
    }
    h = (rotl(v1, 1n) + rotl(v2, 7n) + rotl(v3, 12n) + rotl(v4, 18n)) & MASK
    h = merge(h, v1) & MASK
    h = merge(h, v2) & MASK
    h = merge(h, v3) & MASK
    h = merge(h, v4) & MASK
  } else {
    h = (seed + P5) & MASK
  }
  h = (h + BigInt(len)) & MASK
  for (; p + 8 <= len; p += 8) {
    h ^= round(0n, view.getBigUint64(p, true))
    h = (rotl(h, 27n) * P1 + P4) & MASK
  }
  if (p + 4 <= len) {
    h ^= (BigInt(view.getUint32(p, true)) * P1) & MASK
    h = (rotl(h, 23n) * P2 + P3) & MASK
    p += 4
  }
  for (; p < len; p++) {
    h ^= (BigInt(view.getUint8(p)) * P5) & MASK
    h = (rotl(h, 11n) * P1) & MASK
  }
  h ^= h >> 33n
  h = (h * P2) & MASK
  h ^= h >> 29n
  h = (h * P3) & MASK
  h ^= h >> 32n
  return h
}

/** 16 lowercase hex digits. */
export function hex64(value: bigint): string {
  return value.toString(16).padStart(16, '0')
}
```

```ts
import { sortedKeys } from '../util/sorted'

/**
 * Canonical JSON: object keys sorted at every depth, no whitespace. Numbers use the ECMAScript
 * Number-to-string algorithm, which every engine implements identically. Rejects anything that
 * JSON can't represent exactly (NaN, Infinity, undefined, bigint, functions, symbols).
 */
export function canonicalJson(value: unknown): string {
  if (value === null) return 'null'
  switch (typeof value) {
    case 'boolean':
      return value ? 'true' : 'false'
    case 'string':
      return JSON.stringify(value)
    case 'number':
      if (!Number.isFinite(value)) throw new Error(`canonicalJson: non-finite number ${value}`)
      return JSON.stringify(value)
    case 'object': {
      if (Array.isArray(value)) return `[${value.map(canonicalJson).join(',')}]`
      const obj = value as Record<string, unknown>
      return `{${sortedKeys(obj)
        .map((k) => `${JSON.stringify(k)}:${canonicalJson(obj[k])}`)
        .join(',')}}`
    }
    default:
      throw new Error(`canonicalJson: unsupported ${typeof value}`)
  }
}

/** UTF-8 encoding without TextEncoder (the sim's lib has no DOM/Web APIs). Lone surrogates become U+FFFD. */
export function utf8(s: string): Uint8Array {
  const out: number[] = []
  for (let i = 0; i < s.length; i++) {
    let c = s.charCodeAt(i)
    if (c >= 0xd800 && c <= 0xdbff && i + 1 < s.length) {
      const lo = s.charCodeAt(i + 1)
      if (lo >= 0xdc00 && lo <= 0xdfff) {
        c = 0x10000 + ((c - 0xd800) << 10) + (lo - 0xdc00)
        i++
      }
    }
    if (c >= 0xd800 && c <= 0xdfff) c = 0xfffd
    if (c < 0x80) out.push(c)
    else if (c < 0x800) out.push(0xc0 | (c >> 6), 0x80 | (c & 63))
    else if (c < 0x10000) out.push(0xe0 | (c >> 12), 0x80 | ((c >> 6) & 63), 0x80 | (c & 63))
    else out.push(0xf0 | (c >> 18), 0x80 | ((c >> 12) & 63), 0x80 | ((c >> 6) & 63), 0x80 | (c & 63))
  }
  return Uint8Array.from(out)
}
```

```ts
// xoshiro128** (Blackman & Vigna), 32-bit integer ops only, so it is bit-exact in every engine.
// Seeded through splitmix32; each system gets its own substream (spec §4.4 rule 2).

export type RngState = [number, number, number, number]

export interface Rng {
  /** Next raw 32-bit unsigned output. */
  nextU32(): number
  /** Uniform in [0, 1), 32 bits of precision. */
  next(): number
  /** Uniform integer in [0, n). `n` must be a positive integer <= 2^32. */
  int(n: number): number
  /** Copy of the current state, for snapshots. */
  state(): RngState
}

const rotl = (x: number, k: number): number => ((x << k) | (x >>> (32 - k))) >>> 0

function splitmix32(seed: number): () => number {
  let x = seed >>> 0
  return () => {
    x = (x + 0x9e3779b9) >>> 0
    let z = x
    z = Math.imul(z ^ (z >>> 16), 0x85ebca6b) >>> 0
    z = Math.imul(z ^ (z >>> 13), 0xc2b2ae35) >>> 0
    return (z ^ (z >>> 16)) >>> 0
  }
}

export function rngFromState(initial: RngState): Rng {
  const s = initial.map((v) => v >>> 0) as RngState
  if ((s[0] | s[1] | s[2] | s[3]) === 0) s[0] = 1 // the all-zero state is a fixed point
  const nextU32 = (): number => {
    const result = Math.imul(rotl(Math.imul(s[1], 5) >>> 0, 7), 9) >>> 0
    const t = (s[1] << 9) >>> 0
    s[2] = (s[2] ^ s[0]) >>> 0
    s[3] = (s[3] ^ s[1]) >>> 0
    s[1] = (s[1] ^ s[2]) >>> 0
    s[0] = (s[0] ^ s[3]) >>> 0
    s[2] = (s[2] ^ t) >>> 0
    s[3] = rotl(s[3], 11)
    return result
  }
  return {
    nextU32,
    next: () => nextU32() / 4294967296,
    int: (n) => {
      if (!Number.isInteger(n) || n <= 0 || n > 4294967296) throw new RangeError(`rng.int: bad bound ${n}`)
      return Math.floor((nextU32() / 4294967296) * n)
    },
    state: () => [s[0], s[1], s[2], s[3]],
  }
}

export function createRng(seed: number): Rng {
  const sm = splitmix32(seed)
  return rngFromState([sm(), sm(), sm(), sm()])
}

/** Seed for a named substream: FNV-1a over the name's UTF-16 code units, mixed with the root seed. */
export function deriveSeed(rootSeed: number, name: string): number {
  let h = 0x811c9dc5
  for (let i = 0; i < name.length; i++) h = Math.imul(h ^ name.charCodeAt(i), 0x01000193) >>> 0
  return splitmix32((h ^ Math.imul(rootSeed >>> 0, 0x9e3779b1)) >>> 0)()
}
```

```ts
// Component field types (spec §4.2). Every write goes through coerceField so stored values are canonical.

export const FIELD_TYPES = ['f32', 'f64', 'i32', 'u32', 'bool', 'entity', 'string'] as const
export type FieldType = (typeof FIELD_TYPES)[number]
export type FieldSchema = Readonly<Record<string, FieldType>>
export type FieldValue<T extends FieldType> = T extends 'bool'
  ? boolean
  : T extends 'string'
    ? string
    : number
export type FieldValues<S extends FieldSchema> = { -readonly [K in keyof S]: FieldValue<S[K]> }

const finite = (type: FieldType, v: unknown): number => {
  if (typeof v !== 'number') throw new TypeError(`${type} field expects a number, got ${typeof v}`)
  // NaN's byte pattern is engine-chosen when written to a buffer, so it can't appear in a canonical snapshot.
  if (!Number.isFinite(v)) throw new RangeError(`${type} field must be finite, got ${v}`)
  return v
}

const intIn = (type: FieldType, v: unknown, min: number, max: number): number => {
  const n = finite(type, v)
  if (!Number.isInteger(n) || n < min || n > max) throw new RangeError(`${type} field out of range: ${n}`)
  return n
}

export function coerceField(type: FieldType, value: unknown): number | boolean | string {
  switch (type) {
    case 'f32':
      return Math.fround(finite(type, value))
    case 'f64':
      return finite(type, value)
    case 'i32':
      return intIn(type, value, -2147483648, 2147483647)
    case 'u32':
    case 'entity':
      return intIn(type, value, 0, 4294967295)
    case 'bool':
      if (typeof value !== 'boolean') throw new TypeError(`bool field expects a boolean, got ${typeof value}`)
      return value
    case 'string':
      if (typeof value !== 'string') throw new TypeError(`string field expects a string, got ${typeof value}`)
      return value
  }
}

export function defaultField(type: FieldType): number | boolean | string {
  return type === 'bool' ? false : type === 'string' ? '' : 0
}
```

```ts
import { PHASES, type PluginDef, type SystemDef } from '../define/definitions'

/**
 * Kahn's algorithm that always takes the alphabetically smallest ready node, so the result depends only on
 * the nodes and edges, never on input order. Edges are [from, to]: `from` runs before `to`.
 */
function stableTopo(
  what: string,
  nodes: readonly string[],
  edges: ReadonlyArray<readonly [string, string]>,
): string[] {
  const indegree = new Map<string, number>(nodes.map((n) => [n, 0]))
  const next = new Map<string, string[]>(nodes.map((n) => [n, []]))
  for (const [from, to] of edges) {
    next.get(from)?.push(to)
    indegree.set(to, (indegree.get(to) ?? 0) + 1)
  }
  const ready = nodes.filter((n) => indegree.get(n) === 0)
  const out: string[] = []
  while (ready.length > 0) {
    ready.sort()
    const n = ready.shift() as string
    out.push(n)
    for (const m of next.get(n) ?? []) {
      const d = (indegree.get(m) ?? 0) - 1
      indegree.set(m, d)
      if (d === 0) ready.push(m)
    }
  }
  if (out.length !== nodes.length) {
    const stuck = nodes.filter((n) => !out.includes(n)).sort()
    throw new Error(`${what} ordering has a cycle among: ${stuck.join(', ')}`)
  }
  return out
}

/** Plugins in dependency order, ties broken by name (spec §4.3). */
export function orderPlugins(plugins: readonly PluginDef[]): PluginDef[] {
  const byName = new Map<string, PluginDef>()
  for (const p of plugins) {
    if (byName.has(p.name)) throw new Error(`duplicate plugin "${p.name}"`)
    byName.set(p.name, p)
  }
  const edges: Array<[string, string]> = []
  for (const p of plugins) {
    for (const dep of p.dependsOn) {
      if (!byName.has(dep)) throw new Error(`plugin "${p.name}" depends on unknown plugin "${dep}"`)
      edges.push([dep, p.name])
    }
  }
  return stableTopo('plugin', [...byName.keys()], edges).map((n) => byName.get(n) as PluginDef)
}

/** Systems grouped by phase (fixed order); within a phase, before/after constraints, ties by name. */
export function orderSystems(systems: readonly SystemDef[]): SystemDef[] {
  const byName = new Map<string, SystemDef>()
  for (const s of systems) {
    if (byName.has(s.name)) throw new Error(`duplicate system "${s.name}"`)
    byName.set(s.name, s)
  }
  const ordered: SystemDef[] = []
  for (const phase of PHASES) {
    const inPhase = systems.filter((s) => s.phase === phase)
    const edges: Array<[string, string]> = []
    for (const s of inPhase) {
      for (const [list, dir] of [
        [s.after, 'after'],
        [s.before, 'before'],
      ] as const) {
        for (const ref of list) {
          const other = byName.get(ref)
          if (!other) throw new Error(`system "${s.name}" is ${dir} unknown system "${ref}"`)
          if (other.phase !== s.phase) {
            throw new Error(
              `system "${s.name}" (${s.phase}) is ${dir} "${ref}", which is in a different phase (${other.phase})`,
            )
          }
          edges.push(dir === 'after' ? [ref, s.name] : [s.name, ref])
        }
      }
    }
    for (const n of stableTopo(
      'system',
      inPhase.map((s) => s.name),
      edges,
    ))
      ordered.push(byName.get(n) as SystemDef)
  }
  return ordered
}
```

```ts
import { createWorld, type Entity, type World } from 'koota'
import type { EntityRef, SpawnPart } from '../define/context'
import type { ComponentDef } from '../define/definitions'
import { coerceField, type FieldType } from '../define/fields'
import { sortedKeys } from '../util/sorted'

export type FieldRecord = Record<string, number | boolean | string>

/** One entity's render-flagged components (component id -> field values). */
export interface RenderRow {
  readonly sid: number
  readonly components: Readonly<Record<string, Readonly<FieldRecord>>>
}

/**
 * What changed for the renderer since the last delta (spec §4.7). `changed` rows carry the entity's full
 * render state, so a removed component shows up as its absence. `resync` deltas list every live render
 * entity as added; the renderer drops everything it had first.
 */
export interface RenderDelta {
  readonly resync: boolean
  readonly added: readonly RenderRow[]
  readonly changed: readonly RenderRow[]
  readonly removed: readonly number[]
}

/**
 * Entities behind the facade: Koota stores the data; this class owns StableIds (monotonic, never reused),
 * iteration order (ascending StableId), field coercion and render dirty-tracking. Koota ids never escape.
 */
export class EntityStore {
  private readonly world: World = createWorld()
  private readonly registered: Map<string, ComponentDef>
  private readonly entities = new Map<number, Entity>()
  private readonly live: number[] = [] // ascending: StableIds are monotonic, so spawn appends
  private readonly addedThisTick = new Set<number>()
  private readonly changedThisTick = new Set<number>()
  private readonly removedThisTick = new Set<number>()
  nextId = 1

  constructor(components: readonly ComponentDef[]) {
    this.registered = new Map(components.map((c) => [c.id, c]))
  }

  private check(def: ComponentDef): ComponentDef {
    if (this.registered.get(def.id) !== def)
      throw new Error(`unknown component "${def.id}": register it in a plugin`)
    return def
  }

  private coerce(
    def: ComponentDef,
    values: Readonly<Record<string, unknown>>,
    base: FieldRecord,
  ): FieldRecord {
    const out: FieldRecord = { ...base }
    for (const name of sortedKeys(values)) {
      const type = def.fields[name] as FieldType | undefined
      if (!type) throw new Error(`component "${def.id}" has no field: unknown field "${name}"`)
      out[name] = coerceField(type, values[name])
    }
    return out
  }

  private defaults(def: ComponentDef): FieldRecord {
    return this.coerce(def, {}, def.trait.schema as FieldRecord)
  }

  private read(e: Entity, def: ComponentDef): FieldRecord {
    const raw = e.get(def.trait) as FieldRecord
    const out: FieldRecord = {}
    for (const name of def.fieldNames) out[name] = raw[name] as number | boolean | string
    return out
  }

  private markChanged(sid: number, def: ComponentDef): void {
    if (def.render && !this.addedThisTick.has(sid)) this.changedThisTick.add(sid)
  }

  private alive(sid: number): Entity {
    const e = this.entities.get(sid)
    if (!e) throw new Error(`entity ${sid} is not alive`)
    return e
  }

  /** Spawns with a fresh StableId. */
  spawn(parts: readonly SpawnPart[]): number {
    return this.spawnWithId(this.nextId++, parts)
  }

  /** Spawns with a given StableId (restore only; ids must arrive in ascending order). */
  spawnWithId(sid: number, parts: readonly SpawnPart[]): number {
    const e = this.world.spawn()
    for (const part of parts) {
      const [def, values] = Array.isArray(part) ? part : [part as ComponentDef, {}]
      this.check(def)
      if (e.has(def.trait)) throw new Error(`entity ${sid} already has "${def.id}"`)
      e.add(def.trait(this.coerce(def, values, this.defaults(def))))
    }
    this.entities.set(sid, e)
    this.live.push(sid)
    this.addedThisTick.add(sid)
    return sid
  }

  despawn(sid: number): void {
    const e = this.alive(sid)
    const hadRender = this.renderComponents(e).length > 0
    e.destroy()
    this.entities.delete(sid)
    this.live.splice(this.live.indexOf(sid), 1)
    this.changedThisTick.delete(sid)
    if (this.addedThisTick.has(sid)) this.addedThisTick.delete(sid)
    else if (hadRender) this.removedThisTick.add(sid)
  }

  liveSids(): readonly number[] {
    return this.live
  }

  componentsOf(sid: number): ComponentDef[] {
    const e = this.alive(sid)
    return [...this.registered.values()].filter((c) => e.has(c.trait))
  }

  query(components: readonly ComponentDef[]): EntityRef[] {
    for (const c of components) this.check(c)
    const out: EntityRef[] = []
    for (const sid of this.live) {
      const e = this.entities.get(sid) as Entity
      if (components.every((c) => e.has(c.trait))) out.push(this.makeRef(sid))
    }
    return out
  }

  ref(sid: number): EntityRef | undefined {
    return this.entities.has(sid) ? this.makeRef(sid) : undefined
  }

  private makeRef(sid: number): EntityRef {
    // biome-ignore lint/complexity/noUselessThisAlias: methods below are plain object members
    const store = this
    return {
      sid,
      has: (def) => store.alive(sid).has(store.check(def).trait),
      get: (def) => {
        const e = store.alive(sid)
        if (!e.has(store.check(def).trait)) throw new Error(`entity ${sid} does not have "${def.id}"`)
        return Object.freeze(store.read(e, def)) as never // a copy: mutating it must throw, not silently do nothing
      },
      set: (def, values) => {
        const e = store.alive(sid)
        if (!e.has(store.check(def).trait)) throw new Error(`entity ${sid} does not have "${def.id}"`)
        e.set(def.trait, store.coerce(def, values as Record<string, unknown>, store.read(e, def)))
        store.markChanged(sid, def)
      },
      add: (def, values = {}) => {
        const e = store.alive(sid)
        if (e.has(store.check(def).trait)) throw new Error(`entity ${sid} already has "${def.id}"`)
        e.add(def.trait(store.coerce(def, values as Record<string, unknown>, store.defaults(def))))
        store.markChanged(sid, def)
      },
      remove: (def) => {
        const e = store.alive(sid)
        if (!e.has(store.check(def).trait)) return
        e.remove(def.trait)
        store.markChanged(sid, def)
      },
    }
  }

  private renderComponents(e: Entity): ComponentDef[] {
    return [...this.registered.values()]
      .filter((c) => c.render && e.has(c.trait))
      .sort((a, b) => (a.id < b.id ? -1 : 1))
  }

  private row(sid: number): RenderRow | null {
    const e = this.entities.get(sid) as Entity
    const comps = this.renderComponents(e)
    if (comps.length === 0) return null
    const components: Record<string, FieldRecord> = {}
    for (const c of comps) components[c.id] = this.read(e, c)
    return { sid, components }
  }

  private rows(sids: Iterable<number>): RenderRow[] {
    const out: RenderRow[] = []
    for (const sid of [...sids].sort((a, b) => a - b)) {
      const r = this.entities.has(sid) ? this.row(sid) : null
      if (r) out.push(r)
    }
    return out
  }

  /** Render changes since the last call, then clears the tracking (built-in `render.collect`). */
  takeDelta(resync: boolean): RenderDelta {
    const delta: RenderDelta = resync
      ? { resync: true, added: this.rows(this.live), changed: [], removed: [] }
      : {
          resync: false,
          added: this.rows(this.addedThisTick),
          changed: this.rows([...this.changedThisTick].filter((sid) => !this.addedThisTick.has(sid))),
          removed: [...this.removedThisTick].sort((a, b) => a - b),
        }
    this.addedThisTick.clear()
    this.changedThisTick.clear()
    this.removedThisTick.clear()
    return delta
  }

  dispose(): void {
    this.world.destroy()
  }
}
```

```ts
import type { z } from 'zod'
import type { CommandRecord, EntityRef, SimContext, SpawnPart } from '../define/context'
import {
  type CommandDef,
  type ComponentDef,
  defineSystem,
  type EventDef,
  type PluginDef,
  type ResourceDef,
  type SystemDef,
} from '../define/definitions'
import { canonicalJson } from '../hash/canonical'
import { createRng, deriveSeed, type Rng } from '../rng/rng'
import { orderPlugins, orderSystems } from '../schedule/schedule'
import { sortedKeys } from '../util/sorted'
import { EntityStore, type RenderDelta } from './entity-store'

/** Input to the sim (spec §4.4 rule 4). `source` is a player slot (u8), `seq` a per-source counter (u32). */
export interface Command {
  readonly tick: number
  readonly source: number
  readonly seq: number
  readonly type: string
  readonly payload: unknown
}

export type RejectReason =
  | 'bad-header'
  | 'unknown-command'
  | 'wrong-tick'
  | 'duplicate-seq'
  | 'invalid-payload'

export interface RejectedCommand {
  readonly command: Command
  readonly reason: RejectReason
}

export interface SimEvent {
  readonly type: string
  readonly payload: unknown
}

export interface StepResult {
  /** The tick the sim is at after this step. */
  readonly tick: number
  readonly events: readonly SimEvent[]
  readonly render: RenderDelta
  /** Invalid commands, in input order. The sim has no I/O, so it reports instead of logging. */
  readonly rejected: readonly RejectedCommand[]
}

export interface SimOptions {
  readonly seed: number
  readonly tickHz?: number
  readonly content?: unknown
  readonly plugins: readonly PluginDef[]
}

export interface Sim {
  readonly seed: number
  readonly tickHz: number
  readonly tick: number
  step(commands: readonly Command[]): StepResult
  /** Setup and inspection outside `step` (tests, scene setup). Runtime changes go through commands. */
  spawn(parts: readonly SpawnPart[]): number
  entity(sid: number): EntityRef | undefined
  query(...components: ComponentDef[]): EntityRef[]
  resource<Z extends z.ZodType>(def: ResourceDef<Z>): z.output<Z>
  dispose(): void
}

function deepFreeze<T>(value: T): T {
  if (value !== null && typeof value === 'object' && !Object.isFrozen(value)) {
    Object.freeze(value)
    for (const k of sortedKeys(value as object)) deepFreeze((value as Record<string, unknown>)[k])
  }
  return value
}

function register<T extends { id: string }>(what: string, map: Map<string, T>, items: readonly T[]): void {
  for (const item of items) {
    if (map.has(item.id)) throw new Error(`duplicate ${what} "${item.id}"`)
    map.set(item.id, item)
  }
}

const isU = (n: unknown, max: number): boolean =>
  typeof n === 'number' && Number.isInteger(n) && n >= 0 && n <= max

export async function createSim(opts: SimOptions): Promise<Sim> {
  const tickHz = opts.tickHz ?? 60
  if (!Number.isInteger(tickHz) || tickHz < 1 || tickHz > 1000)
    throw new Error(`tickHz must be an integer 1..1000`)
  const dt = 1 / tickHz
  const plugins = orderPlugins(opts.plugins)

  const components = new Map<string, ComponentDef>()
  const commandDefs = new Map<string, CommandDef>()
  const eventDefs = new Map<string, EventDef>()
  const resourceDefs = new Map<string, ResourceDef>()
  for (const p of plugins) {
    register('component', components, p.components)
    register('command', commandDefs, p.commands)
    register('event', eventDefs, p.events)
    register('resource', resourceDefs, p.resources)
  }

  // Content: an independent, canonical, deep-frozen copy (spec §4.4 rule 6).
  const contentJson = canonicalJson(opts.content === undefined ? {} : opts.content)
  const content = deepFreeze(JSON.parse(contentJson))
  const componentList = [...components.values()]
  const store = new EntityStore(componentList)
  const resources = new Map<string, unknown>()
  for (const def of resourceDefs.values()) resources.set(def.id, def.schema.parse(def.init()))

  let tick = 0
  let fullResync = true // a renderer starts empty, so the first delta is a resync
  let events: SimEvent[] = []
  let pendingDespawn = new Set<number>()
  let commandsByType = new Map<string, Array<CommandRecord<unknown>>>()
  let lastDelta: RenderDelta = { resync: false, added: [], changed: [], removed: [] }

  // Built-ins. Every input system runs after commands.apply; every cleanup system before entities.flush.
  const builtins: SystemDef[] = [
    defineSystem({ name: 'commands.apply', phase: 'input', run: () => {} }),
    defineSystem({
      name: 'entities.flush',
      phase: 'cleanup',
      run: () => {
        for (const sid of [...pendingDespawn].sort((a, b) => a - b)) store.despawn(sid)
        pendingDespawn = new Set()
      },
    }),
    defineSystem({
      name: 'render.collect',
      phase: 'cleanup',
      after: ['entities.flush'],
      run: () => {
        lastDelta = store.takeDelta(fullResync)
        fullResync = false
      },
    }),
  ]
  const builtinNames = new Set(builtins.map((s) => s.name))
  const userSystems = plugins.flatMap((p) => p.systems)
  for (const s of userSystems)
    if (builtinNames.has(s.name)) throw new Error(`system name "${s.name}" is reserved`)
  const wired = userSystems.map((s) => {
    if (s.phase === 'input' && !s.after.includes('commands.apply'))
      return { ...s, after: [...s.after, 'commands.apply'] }
    if (s.phase === 'cleanup' && !s.before.includes('entities.flush'))
      return { ...s, before: [...s.before, 'entities.flush'] }
    return s
  })
  const systems = orderSystems([...builtins, ...wired])
  const rngs = new Map<string, Rng>(systems.map((s) => [s.name, createRng(deriveSeed(opts.seed, s.name))]))

  const resourceOf = <Z extends z.ZodType>(def: ResourceDef<Z>): z.output<Z> => {
    if (resourceDefs.get(def.id) !== def)
      throw new Error(`unknown resource "${def.id}": register it in a plugin`)
    return resources.get(def.id) as z.output<Z>
  }

  const contexts = systems.map((system) => {
    const ctx: SimContext = {
      get tick() {
        return tick
      },
      dt,
      get rng() {
        return rngs.get(system.name) as Rng
      },
      content,
      query: (...cs) => store.query(cs),
      entity: (sid) => store.ref(sid),
      spawn: (...parts) => store.spawn(parts),
      despawn: (sid) => {
        if (!store.ref(sid)) throw new Error(`despawn: entity ${sid} is not alive`)
        pendingDespawn.add(sid)
      },
      commands: {
        of: <Z extends z.ZodType>(def: CommandDef<Z>) => {
          if (commandDefs.get(def.id) !== def)
            throw new Error(`unknown command "${def.id}": register it in a plugin`)
          return (commandsByType.get(def.id) ?? []) as ReadonlyArray<CommandRecord<z.output<Z>>>
        },
      },
      emit: (def, payload) => {
        if (eventDefs.get(def.id) !== def)
          throw new Error(`unknown event "${def.id}": register it in a plugin`)
        const parsed = def.schema.safeParse(payload)
        if (!parsed.success) throw new Error(`event "${def.id}" payload invalid: ${parsed.error.message}`)
        events.push({ type: def.id, payload: parsed.data })
      },
      resource: resourceOf,
    }
    return { system, ctx }
  })

  function intake(commands: readonly Command[]): RejectedCommand[] {
    const rejected: RejectedCommand[] = []
    const accepted: Array<Command & { parsed: unknown }> = []
    const seen = new Set<string>()
    for (const c of commands) {
      if (
        !isU(c.tick, 4294967295) ||
        !isU(c.source, 255) ||
        !isU(c.seq, 4294967295) ||
        typeof c.type !== 'string'
      ) {
        rejected.push({ command: c, reason: 'bad-header' })
        continue
      }
      const def = commandDefs.get(c.type)
      if (!def) {
        rejected.push({ command: c, reason: 'unknown-command' })
        continue
      }
      if (c.tick !== tick) {
        rejected.push({ command: c, reason: 'wrong-tick' })
        continue
      }
      const key = `${c.source}:${c.seq}`
      if (seen.has(key)) {
        rejected.push({ command: c, reason: 'duplicate-seq' })
        continue
      }
      const parsed = def.schema.safeParse(c.payload)
      if (!parsed.success) {
        rejected.push({ command: c, reason: 'invalid-payload' })
        continue
      }
      seen.add(key)
      accepted.push({ ...c, parsed: parsed.data })
    }
    accepted.sort((a, b) => a.source - b.source || a.seq - b.seq)
    commandsByType = new Map()
    for (const c of accepted) {
      const list = commandsByType.get(c.type) ?? []
      list.push({ source: c.source, seq: c.seq, payload: c.parsed })
      commandsByType.set(c.type, list)
    }
    return rejected
  }

  const sim: Sim = {
    seed: opts.seed,
    tickHz,
    get tick() {
      return tick
    },
    step(commands) {
      const rejected = intake(commands)
      events = []
      for (const { system, ctx } of contexts) system.run(ctx)
      tick += 1
      commandsByType = new Map()
      return { tick, events, render: lastDelta, rejected }
    },
    spawn: (parts) => store.spawn(parts),
    entity: (sid) => store.ref(sid),
    query: (...cs) => store.query(cs),
    resource: resourceOf,
    dispose: () => store.dispose(),
  }
  return sim
}
```

```ts
// Snapshot format v1 (spec §4.6), little-endian throughout:
//   header   "AUTO" | version u16 | schemaHash u64 | contentHash u64 | tick u32 | tickHz u16
//   sections [tag u8 | byteLength u32 | payload] in fixed order: 1 strings, 2 rng, 3 resources, 4 entities
// Floats are written with DataView; values are finite by construction (coerceField), so bytes are canonical.

import type { ComponentDef } from '../define/definitions'
import type { FieldType } from '../define/fields'
import { utf8 } from '../hash/canonical'
import type { RngState } from '../rng/rng'
import type { FieldRecord } from './entity-store'

export const SNAPSHOT_VERSION = 1
const MAGIC = [65, 85, 84, 79] // "AUTO"
const TAG = { strings: 1, rng: 2, resources: 3, entities: 4 } as const

export class SnapshotFormatError extends Error {
  constructor(message: string) {
    super(`snapshot format: ${message}`)
    this.name = 'SnapshotFormatError'
  }
}

export class SnapshotMismatchError extends Error {
  readonly field: 'schemaHash' | 'contentHash' | 'tickHz'
  readonly expected: string
  readonly actual: string
  constructor(field: 'schemaHash' | 'contentHash' | 'tickHz', expected: string, actual: string) {
    super(`snapshot ${field} mismatch: this sim has ${expected}, the snapshot has ${actual}`)
    this.name = 'SnapshotMismatchError'
    this.field = field
    this.expected = expected
    this.actual = actual
  }
}

export interface SnapshotData {
  readonly schemaHash: bigint
  readonly contentHash: bigint
  readonly tick: number
  readonly tickHz: number
  /** One RNG state per system, in execution order. */
  readonly rng: ReadonlyArray<{ readonly name: string; readonly state: RngState }>
  /** Canonical JSON per resource, sorted by id. */
  readonly resources: ReadonlyArray<{ readonly id: string; readonly json: string }>
  readonly nextId: number
  /** Live entities in ascending StableId order; component id -> field values. */
  readonly entities: ReadonlyArray<{
    readonly sid: number
    readonly components: ReadonlyMap<string, FieldRecord>
  }>

class Writer {
  private buf = new Uint8Array(256)
  private view = new DataView(this.buf.buffer)
  length = 0
  private grow(n: number): void {
    if (this.length + n <= this.buf.length) return
    let size = this.buf.length * 2
    while (size < this.length + n) size *= 2
    const next = new Uint8Array(size)
    next.set(this.buf)
    this.buf = next
    this.view = new DataView(next.buffer)
  }
  u8(v: number): void {
    this.grow(1)
    this.view.setUint8(this.length, v)
    this.length += 1
  }
  u16(v: number): void {
    this.grow(2)
    this.view.setUint16(this.length, v, true)
    this.length += 2
  }
  u32(v: number): void {
    this.grow(4)
    this.view.setUint32(this.length, v, true)
    this.length += 4
  }
  i32(v: number): void {
    this.grow(4)
    this.view.setInt32(this.length, v, true)
    this.length += 4
  }
  u64(v: bigint): void {
    this.grow(8)
    this.view.setBigUint64(this.length, v, true)
    this.length += 8
  }
  f32(v: number): void {
    this.grow(4)
    this.view.setFloat32(this.length, v, true)
    this.length += 4
  }
  f64(v: number): void {
    this.grow(8)
    this.view.setFloat64(this.length, v, true)
    this.length += 8
  }
  bytes(b: Uint8Array): void {
    this.grow(b.length)
    this.buf.set(b, this.length)
    this.length += b.length
  }
  section(tag: number, body: Writer): void {
    this.u8(tag)
    this.u32(body.length)
    this.bytes(body.done())
  }
  done(): Uint8Array {
    return this.buf.slice(0, this.length)
  }
}

class Reader {
  private readonly view: DataView
  pos = 0
  constructor(private readonly bytes: Uint8Array) {
    this.view = new DataView(bytes.buffer, bytes.byteOffset, bytes.byteLength)
  }
  private need(n: number): number {
    if (this.pos + n > this.bytes.length) throw new SnapshotFormatError(`truncated at byte ${this.pos}`)
    const at = this.pos
    this.pos += n
    return at
  }
  u8(): number {
    return this.view.getUint8(this.need(1))
  }
  u16(): number {
    return this.view.getUint16(this.need(2), true)
  }
  u32(): number {
    return this.view.getUint32(this.need(4), true)
  }
  i32(): number {
    return this.view.getInt32(this.need(4), true)
  }
  u64(): bigint {
    return this.view.getBigUint64(this.need(8), true)
  }
  f32(): number {
    return this.view.getFloat32(this.need(4), true)
  }
  f64(): number {
    return this.view.getFloat64(this.need(8), true)
  }
  take(n: number): Uint8Array {
    const at = this.need(n)
    return this.bytes.subarray(at, at + n)
  }
  section(tag: number): Reader {
    const got = this.u8()
    if (got !== tag) throw new SnapshotFormatError(`expected section ${tag}, found ${got}`)
    return new Reader(this.take(this.u32()))
  }
  end(what: string): void {
    if (this.pos !== this.bytes.length)
      throw new SnapshotFormatError(`${this.bytes.length - this.pos} trailing bytes in ${what}`)
  }
}

function decodeUtf8(b: Uint8Array): string {
  let s = ''
  for (let i = 0; i < b.length; ) {
    const c = b[i] as number
    let cp: number
    if (c < 0x80) {
      cp = c
      i += 1
    } else if (c < 0xe0) {
      cp = ((c & 31) << 6) | ((b[i + 1] as number) & 63)
      i += 2
    } else if (c < 0xf0) {
      cp = ((c & 15) << 12) | (((b[i + 1] as number) & 63) << 6) | ((b[i + 2] as number) & 63)
      i += 3
    } else {
      cp =
        ((c & 7) << 18) |
        (((b[i + 1] as number) & 63) << 12) |
        (((b[i + 2] as number) & 63) << 6) |
        ((b[i + 3] as number) & 63)
      i += 4
    }
    s += String.fromCodePoint(cp)
  }
  return s
}

const compareStr = (a: string, b: string): number => (a < b ? -1 : a > b ? 1 : 0)

export function encodeSnapshot(data: SnapshotData, components: readonly ComponentDef[]): Uint8Array {
  const comps = [...components].sort((a, b) => compareStr(a.id, b.id))

  // String table: every id, name and string field value, sorted and de-duplicated.
  const set = new Set<string>()
  for (const r of data.rng) set.add(r.name)
  for (const r of data.resources) set.add(r.id)
  for (const c of comps) set.add(c.id)
  for (const e of data.entities)
    for (const c of comps) {
      const rec = e.components.get(c.id)
      if (rec) for (const f of c.fieldNames) if (c.fields[f] === 'string') set.add(rec[f] as string)
    }
  const strings = [...set].sort(compareStr)
  const index = new Map(strings.map((s, i) => [s, i]))
  const idx = (s: string): number => index.get(s) as number

  const out = new Writer()
  for (const b of MAGIC) out.u8(b)
  out.u16(SNAPSHOT_VERSION)
  out.u64(data.schemaHash)
  out.u64(data.contentHash)
  out.u32(data.tick)
  out.u16(data.tickHz)

  const s = new Writer()
  s.u32(strings.length)
  for (const str of strings) {
    const b = utf8(str)
    s.u32(b.length)
    s.bytes(b)
  }
  out.section(TAG.strings, s)

  const r = new Writer()
  r.u32(data.rng.length)
  for (const { name, state } of data.rng) {
    r.u32(idx(name))
    for (const v of state) r.u32(v)
  }
  out.section(TAG.rng, r)

  const res = new Writer()
  res.u32(data.resources.length)
  for (const { id, json } of data.resources) {
    const b = utf8(json)
    res.u32(idx(id))
    res.u32(b.length)
    res.bytes(b)
  }
  out.section(TAG.resources, res)

  const en = new Writer()
  en.u32(data.nextId)
  en.u32(data.entities.length)
  for (const e of data.entities) en.u32(e.sid)
  en.u32(comps.length)
  for (const c of comps) {
    en.u32(idx(c.id))
    const present = data.entities.map((e) => e.components.get(c.id))
    for (let i = 0; i < present.length; i += 8) {
      let byte = 0
      for (let bit = 0; bit < 8 && i + bit < present.length; bit++) if (present[i + bit]) byte |= 1 << bit
      en.u8(byte)
    }
    for (const f of c.fieldNames) {
      const type = c.fields[f] as FieldType
      for (const rec of present) {
        if (!rec) continue
        const v = rec[f]
        if (type === 'f32') en.f32(v as number)
        else if (type === 'f64') en.f64(v as number)
        else if (type === 'i32') en.i32(v as number)
        else if (type === 'bool') en.u8(v ? 1 : 0)
        else if (type === 'string') en.u32(idx(v as string))
        else en.u32(v as number) // u32, entity
      }
    }
  }
  out.section(TAG.entities, en)
  return out.done()
}

export function decodeSnapshot(bytes: Uint8Array, components: readonly ComponentDef[]): SnapshotData {
  const comps = [...components].sort((a, b) => compareStr(a.id, b.id))
  const rd = new Reader(bytes)
  for (const b of MAGIC) if (rd.u8() !== b) throw new SnapshotFormatError('bad magic (not an AUTO snapshot)')
  const version = rd.u16()
  if (version !== SNAPSHOT_VERSION) throw new SnapshotFormatError(`unsupported version ${version}`)
  const schemaHash = rd.u64()
  const contentHash = rd.u64()
  const tick = rd.u32()
  const tickHz = rd.u16()

  const s = rd.section(TAG.strings)
  const strings: string[] = []
  for (let n = s.u32(); n > 0; n--) strings.push(decodeUtf8(s.take(s.u32())))
  s.end('strings')
  const str = (i: number): string => {
    const v = strings[i]
    if (v === undefined) throw new SnapshotFormatError(`string index ${i} out of range`)
    return v
  }

  const r = rd.section(TAG.rng)
  const rng: Array<{ name: string; state: RngState }> = []
  for (let n = r.u32(); n > 0; n--)
    rng.push({ name: str(r.u32()), state: [r.u32(), r.u32(), r.u32(), r.u32()] })
  r.end('rng')

  const res = rd.section(TAG.resources)
  const resources: Array<{ id: string; json: string }> = []
  for (let n = res.u32(); n > 0; n--) {
    const id = str(res.u32())
    resources.push({ id, json: decodeUtf8(res.take(res.u32())) })
  }
  res.end('resources')

  const en = rd.section(TAG.entities)
  const nextId = en.u32()
  const sids: number[] = []
  for (let n = en.u32(); n > 0; n--) sids.push(en.u32())
  const entities = sids.map((sid) => ({ sid, components: new Map<string, FieldRecord>() }))
  const compCount = en.u32()
  if (compCount !== comps.length)
    throw new SnapshotFormatError(`expected ${comps.length} components, found ${compCount}`)
  for (const c of comps) {
    if (str(en.u32()) !== c.id) throw new SnapshotFormatError(`component order mismatch at "${c.id}"`)
    const present: boolean[] = []
    for (let i = 0; i < sids.length; i += 8) {
      const byte = en.u8()
      for (let bit = 0; bit < 8 && i + bit < sids.length; bit++) present.push((byte & (1 << bit)) !== 0)
    }
    const recs = entities.map((e, i) => {
      if (!present[i]) return undefined
      const rec: FieldRecord = {}
      e.components.set(c.id, rec)
      return rec
    })
    for (const f of c.fieldNames) {
      const type = c.fields[f] as FieldType
      for (const rec of recs) {
        if (!rec) continue
        if (type === 'f32') rec[f] = en.f32()
        else if (type === 'f64') rec[f] = en.f64()
        else if (type === 'i32') rec[f] = en.i32()
        else if (type === 'bool') rec[f] = en.u8() === 1
        else if (type === 'string') rec[f] = str(en.u32())
        else rec[f] = en.u32()
      }
    }
  }
  en.end('entities')
  rd.end('snapshot')
  return { schemaHash, contentHash, tick, tickHz, rng, resources, nextId, entities }
}
```

```ts
function deepFreeze<T>(value: T): T {
  if (value !== null && typeof value === 'object' && !Object.isFrozen(value)) {
    Object.freeze(value)
    for (const k of sortedKeys(value as object)) deepFreeze((value as Record<string, unknown>)[k])

  return value
}

function register<T extends { id: string }>(what: string, map: Map<string, T>, items: readonly T[]): void {
  for (const item of items) {
    if (map.has(item.id)) throw new Error(`duplicate ${what} "${item.id}"`)
    map.set(item.id, item)
  }
}

const isU = (n: unknown, max: number): boolean =>
  typeof n === 'number' && Number.isInteger(n) && n >= 0 && n <= max

export async function createSim(opts: SimOptions): Promise<Sim> {
  const tickHz = opts.tickHz ?? 60
  if (!Number.isInteger(tickHz) || tickHz < 1 || tickHz > 1000)
    throw new Error(`tickHz must be an integer 1..1000`)
  const dt = 1 / tickHz
  const plugins = orderPlugins(opts.plugins)

  const components = new Map<string, ComponentDef>()
  const commandDefs = new Map<string, CommandDef>()
  const eventDefs = new Map<string, EventDef>()
  const resourceDefs = new Map<string, ResourceDef>()
  for (const p of plugins) {
    register('component', components, p.components)
    register('command', commandDefs, p.commands)
    register('event', eventDefs, p.events)
    register('resource', resourceDefs, p.resources)
  }

  // Content: an independent, canonical, deep-frozen copy (spec §4.4 rule 6).
  const contentJson = canonicalJson(opts.content === undefined ? {} : opts.content)
  const content = deepFreeze(JSON.parse(contentJson))
  const contentHash = xxhash64(utf8(contentJson))
  const componentList = [...components.values()]
  let store = new EntityStore(componentList)
  const resources = new Map<string, unknown>()
  for (const def of resourceDefs.values()) resources.set(def.id, def.schema.parse(def.init()))

  let tick = 0
  let fullResync = true // a renderer starts empty, so the first delta is a resync
  let events: SimEvent[] = []
  let pendingDespawn = new Set<number>()
  let commandsByType = new Map<string, Array<CommandRecord<unknown>>>()
  let lastDelta: RenderDelta = { resync: false, added: [], changed: [], removed: [] }

  // Built-ins. Every input system runs after commands.apply; every cleanup system before entities.flush.
  const builtins: SystemDef[] = [
    defineSystem({ name: 'commands.apply', phase: 'input', run: () => {} }),
    defineSystem({
      name: 'entities.flush',
      phase: 'cleanup',
      run: () => {
        for (const sid of [...pendingDespawn].sort((a, b) => a - b)) store.despawn(sid)
        pendingDespawn = new Set()
      },
    }),
    defineSystem({
      name: 'render.collect',
      phase: 'cleanup',
      after: ['entities.flush'],
      run: () => {
        lastDelta = store.takeDelta(fullResync)
        fullResync = false
      },
    }),
  ]
  const builtinNames = new Set(builtins.map((s) => s.name))
  const userSystems = plugins.flatMap((p) => p.systems)
  for (const s of userSystems)
    if (builtinNames.has(s.name)) throw new Error(`system name "${s.name}" is reserved`)
  const wired = userSystems.map((s) => {
    if (s.phase === 'input' && !s.after.includes('commands.apply'))
      return { ...s, after: [...s.after, 'commands.apply'] }
    if (s.phase === 'cleanup' && !s.before.includes('entities.flush'))
      return { ...s, before: [...s.before, 'entities.flush'] }
    return s
  })
  const systems = orderSystems([...builtins, ...wired])
  const rngs = new Map<string, Rng>(systems.map((s) => [s.name, createRng(deriveSeed(opts.seed, s.name))]))

  // Everything that must match for a snapshot to be restorable here.
  const sortedIds = (m: Map<string, unknown>) => [...m.keys()].sort()
  const schemaHash = xxhash64(
    utf8(
      canonicalJson({
        plugins: plugins.map((p) => p.name),
        components: componentList
          .map((c) => ({ id: c.id, fields: c.fields, render: c.render }))
          .sort((a, b) => (a.id < b.id ? -1 : 1)),
        commands: sortedIds(commandDefs),
        events: sortedIds(eventDefs),
        resources: sortedIds(resourceDefs),
        systems: systems.map((s) => `${s.phase}:${s.name}`),
      }),
    ),
  )

  const resourceOf = <Z extends z.ZodType>(def: ResourceDef<Z>): z.output<Z> => {
    if (resourceDefs.get(def.id) !== def)
      throw new Error(`unknown resource "${def.id}": register it in a plugin`)
    return resources.get(def.id) as z.output<Z>
  }

  const contexts = systems.map((system) => {
    const ctx: SimContext = {
      get tick() {
        return tick
      },
      dt,
      get rng() {
        return rngs.get(system.name) as Rng
      },
      content,
      query: (...cs) => store.query(cs),
      entity: (sid) => store.ref(sid),
      spawn: (...parts) => store.spawn(parts),
      despawn: (sid) => {
        if (!store.ref(sid)) throw new Error(`despawn: entity ${sid} is not alive`)
        pendingDespawn.add(sid)
      },
      commands: {
        of: <Z extends z.ZodType>(def: CommandDef<Z>) => {
          if (commandDefs.get(def.id) !== def)
            throw new Error(`unknown command "${def.id}": register it in a plugin`)
          return (commandsByType.get(def.id) ?? []) as ReadonlyArray<CommandRecord<z.output<Z>>>
        },
      },
      emit: (def, payload) => {
        if (eventDefs.get(def.id) !== def)
          throw new Error(`unknown event "${def.id}": register it in a plugin`)
        const parsed = def.schema.safeParse(payload)
        if (!parsed.success) throw new Error(`event "${def.id}" payload invalid: ${parsed.error.message}`)
        events.push({ type: def.id, payload: parsed.data })
      },
      resource: resourceOf,
    }
    return { system, ctx }
  })

  function intake(commands: readonly Command[]): RejectedCommand[] {
    const rejected: RejectedCommand[] = []
    const accepted: Array<Command & { parsed: unknown }> = []
    const seen = new Set<string>()
    for (const c of commands) {
      if (
        !isU(c.tick, 4294967295) ||
        !isU(c.source, 255) ||
        !isU(c.seq, 4294967295) ||
        typeof c.type !== 'string'
      ) {
        rejected.push({ command: c, reason: 'bad-header' })
        continue
      }
      const def = commandDefs.get(c.type)
      if (!def) {
        rejected.push({ command: c, reason: 'unknown-command' })
        continue
      }
      if (c.tick !== tick) {
        rejected.push({ command: c, reason: 'wrong-tick' })
        continue
      }
      const key = `${c.source}:${c.seq}`
      if (seen.has(key)) {
        rejected.push({ command: c, reason: 'duplicate-seq' })
        continue
      }
      const parsed = def.schema.safeParse(c.payload)
      if (!parsed.success) {
        rejected.push({ command: c, reason: 'invalid-payload' })
        continue
      }
      seen.add(key)
      accepted.push({ ...c, parsed: parsed.data })
    }
    accepted.sort((a, b) => a.source - b.source || a.seq - b.seq)
    commandsByType = new Map()
    for (const c of accepted) {
      const list = commandsByType.get(c.type) ?? []
      list.push({ source: c.source, seq: c.seq, payload: c.parsed })
      commandsByType.set(c.type, list)
    }
    return rejected
  }

  const sim: Sim = {
    seed: opts.seed,
    tickHz,
    get tick() {
      return tick
    },
    step(commands) {
      const rejected = intake(commands)
      events = []
      for (const { system, ctx } of contexts) system.run(ctx)
      tick += 1
      commandsByType = new Map()
      return { tick, events, render: lastDelta, rejected }
    },
    spawn: (parts) => store.spawn(parts),
    entity: (sid) => store.ref(sid),
    query: (...cs) => store.query(cs),
    resource: resourceOf,
    snapshot() {
      const entities = store.liveSids().map((sid) => {
        const ref = store.ref(sid) as EntityRef
        const map = new Map<string, FieldRecord>()
        for (const c of store.componentsOf(sid)) map.set(c.id, ref.get(c) as FieldRecord)
        return { sid, components: map }
      })
      const resourceRows = sortedIds(resourceDefs).map((id) => {
        const def = resourceDefs.get(id) as ResourceDef
        const checked = def.schema.safeParse(resources.get(id))
        if (!checked.success)
          throw new Error(`resource "${id}" no longer matches its schema: ${checked.error.message}`)
        return { id, json: canonicalJson(resources.get(id)) }
      })
      return encodeSnapshot(
        {
          schemaHash,
          contentHash,
          tick,
          tickHz,
          rng: systems.map((s) => ({ name: s.name, state: (rngs.get(s.name) as Rng).state() })),
          resources: resourceRows,
          nextId: store.nextId,
          entities,
        },
        componentList,
      )
    },
    restore(bytes) {
      const data = decodeSnapshot(bytes, componentList)
      if (data.schemaHash !== schemaHash)
        throw new SnapshotMismatchError('schemaHash', hex64(schemaHash), hex64(data.schemaHash))
      if (data.contentHash !== contentHash) {
        throw new SnapshotMismatchError('contentHash', hex64(contentHash), hex64(data.contentHash))
      }
      if (data.tickHz !== tickHz)
        throw new SnapshotMismatchError('tickHz', String(tickHz), String(data.tickHz))
      // Build everything first; swap only when it all validated, so a bad snapshot leaves this sim untouched.
      const next = new EntityStore(componentList)
      try {
        for (const e of data.entities) {
          next.spawnWithId(
            e.sid,
            [...e.components].map(([id, values]) => [components.get(id) as ComponentDef, values] as const),
          )
        }
        next.nextId = data.nextId
        next.takeDelta(false)
        const nextResources = new Map<string, unknown>()
        for (const { id, json } of data.resources) {
          const def = resourceDefs.get(id)
          if (!def) throw new SnapshotFormatError(`unknown resource "${id}"`)
          nextResources.set(id, def.schema.parse(JSON.parse(json)))
        }
        const nextRngs = new Map<string, Rng>(data.rng.map((r) => [r.name, rngFromState(r.state)]))
        if (nextRngs.size !== rngs.size || systems.some((s) => !nextRngs.has(s.name))) {
          throw new SnapshotFormatError('rng streams do not match the systems')
        }
        store.dispose()
        store = next
        for (const [id, v] of nextResources) resources.set(id, v)
        for (const [name, r] of nextRngs) rngs.set(name, r)
      } catch (err) {
        if (store !== next) next.dispose()
        throw err instanceof SnapshotFormatError ? err : new SnapshotFormatError(String(err))
      }
      tick = data.tick
      fullResync = true
      pendingDespawn = new Set()
      events = []
    },
    hash() {
      return hex64(xxhash64(sim.snapshot()))
    },
    dispose: () => store.dispose(),
  }
  return sim
}
```

```ts
import { parseSync } from 'oxc-parser'

// Determinism boundary for packages/sim (A0+A1 spec §3.3 and §11). Works on the AST, so comments, strings,
// property keys and type positions never produce false findings.

export type Rule =
  | 'banned-global'
  | 'math-member'
  | 'pow-operator'
  | 'key-enumeration'
  | 'import'
  | 'parse-error'

export interface Finding {
  readonly file: string
  readonly line: number
  readonly col: number
  readonly rule: Rule
  readonly message: string
}

/** No I/O, no wall clock, no host APIs (law 5). */
export const BANNED_GLOBALS: ReadonlySet<string> = new Set([
  'window',
  'self',
  'document',
  'navigator',
  'location',
  'history',
  'console',
  'requestAnimationFrame',
  'cancelAnimationFrame',
  'fetch',
  'XMLHttpRequest',
  'WebSocket',
  'Worker',
  'localStorage',
  'sessionStorage',
  'indexedDB',
  'crypto',
  'process',
  'globalThis',
  'Date',
  'performance',
  'setTimeout',
  'setInterval',
  'clearTimeout',
  'clearInterval',
  'queueMicrotask',
  'setImmediate',
  'eval',
  'Function',
])

/** Math members that IEEE-754 / ECMAScript define exactly (S5 verdict). Everything else is engine-dependent. */
export const MATH_ALLOWED: ReadonlySet<string> = new Set([
  'sqrt',
  'fround',
  'round',
  'floor',
  'ceil',
  'trunc',
  'abs',
  'min',
  'max',
  'sign',
  'imul',
])

const KEY_ENUMERATION = new Set(['keys', 'values', 'entries', 'getOwnPropertyNames', 'getOwnPropertySymbols'])

export const IMPORT_ALLOWED: ReadonlySet<string> = new Set([
  'koota',
  'zod',
  '@dimforge/rapier2d-deterministic-compat',
  '@dimforge/rapier3d-deterministic-compat',
])

// Keys whose subtree is type-only: skipped entirely.
const TYPE_KEYS = new Set([
  'typeAnnotation',
  'returnType',
  'typeParameters',
  'typeArguments',
  'superTypeArguments',
  'implements',
])
const TYPE_NODES = new Set([
  'TSInterfaceDeclaration',
  'TSTypeAliasDeclaration',
  'TSDeclareFunction',
  'TSModuleDeclaration',
])
// Identifier positions that name something rather than reference it.
const BINDING_KEYS = new Set(['id', 'params', 'local', 'imported', 'exported', 'label'])

type Node = { type: string; start: number; [k: string]: unknown }
const isNode = (v: unknown): v is Node =>
  typeof v === 'object' && v !== null && typeof (v as { type?: unknown }).type === 'string'

function isReference(key: string, parent: Node | null): boolean {
  if (!parent) return true
  if (BINDING_KEYS.has(key)) return false
  if (parent.type === 'CatchClause' && key === 'param') return false
  if (key === 'property' && parent.type === 'MemberExpression' && !parent.computed) return false
  if (key === 'key' && !parent.computed) return false // object/class property and method names
  return true
}

const importOk = (source: string): boolean =>
  source.startsWith('./') || source.startsWith('../') || IMPORT_ALLOWED.has(source)

export function checkSource(file: string, code: string): Finding[] {
  const lineStarts = [0]
  for (let i = 0; i < code.length; i++) if (code[i] === '\n') lineStarts.push(i + 1)
  const at = (offset: number) => {
    let lo = 0
    let hi = lineStarts.length - 1
    while (lo < hi) {
      const mid = (lo + hi + 1) >> 1
      if ((lineStarts[mid] as number) <= offset) lo = mid
      else hi = mid - 1
    }
    return { line: lo + 1, col: offset - (lineStarts[lo] as number) + 1 }
  }
  const findings: Finding[] = []
  const report = (node: Node, rule: Rule, message: string) =>
    findings.push({ file, ...at(node.start), rule, message })

  const parsed = parseSync(file, code)
  if (parsed.errors.length > 0) {
    findings.push({
      file,
      line: 1,
      col: 1,
      rule: 'parse-error',
      message: parsed.errors.map((e) => e.message).join('; '),
    })
    return findings
  }
  const enumerationExempt = file.replaceAll('\\', '/').endsWith('/util/sorted.ts')

  const visit = (node: Node, key: string, parent: Node | null): void => {
    if (TYPE_NODES.has(node.type)) return
    switch (node.type) {
      case 'ImportDeclaration':
      case 'ExportNamedDeclaration':
      case 'ExportAllDeclaration': {
        const source = (node.source as { value?: string } | null)?.value
        if (
          source !== undefined &&
          node.importKind !== 'type' &&
          node.exportKind !== 'type' &&
          !importOk(source)
        ) {
          report(node, 'import', `import of "${source}" is not allowed in the sim`)
        }
        break
      }
      case 'ImportExpression': {
        const src = node.source as Node & { value?: unknown }
        if (src.type !== 'Literal' || typeof src.value !== 'string' || !importOk(src.value)) {
          report(node, 'import', 'dynamic import must be a string literal from the allowlist')
        }
        break
      }
      case 'BinaryExpression':
      case 'AssignmentExpression':
        if (node.operator === '**' || node.operator === '**=') {
          report(
            node,
            'pow-operator',
            `"${node.operator}" is engine-dependent; use pow from automata-sim/math`,
          )
        }
        break
      case 'ForInStatement':
        if (!enumerationExempt)
          report(node, 'key-enumeration', 'for...in order is engine-dependent; use sortedKeys()')
        break
      case 'MemberExpression': {
        const obj = node.object as Node & { name?: string }
        const prop = node.property as Node & { name?: string; value?: unknown }
        const name = node.computed ? (typeof prop.value === 'string' ? prop.value : undefined) : prop.name
        if (
          obj.type === 'Identifier' &&
          obj.name === 'Math' &&
          (name === undefined || !MATH_ALLOWED.has(name))
        ) {
          report(
            node,
            'math-member',
            `Math.${name ?? '[computed]'} is not bit-exact across engines; use automata-sim/math`,
          )
        }
        if (
          obj.type === 'Identifier' &&
          (obj.name === 'Object' || obj.name === 'Reflect') &&
          !enumerationExempt
        ) {
          if (name !== undefined && (KEY_ENUMERATION.has(name) || name === 'ownKeys')) {
            report(
              node,
              'key-enumeration',
              `${obj.name}.${name} order is engine-dependent; use sortedKeys()/sortedEntries()`,
            )
          }
        }
        break
      }
      case 'Identifier': {
        const name = node.name as string
        if (!isReference(key, parent)) break
        if (BANNED_GLOBALS.has(name))
          report(node, 'banned-global', `"${name}" is not available in the sim (no I/O, no clock)`)
        if (name === 'Math' && !(parent?.type === 'MemberExpression' && key === 'object')) {
          report(node, 'math-member', 'Math may only be used as Math.<allowed member>')
        }
        break
      }
    }
    for (const [k, v] of Object.entries(node)) {
      if (k === 'type' || TYPE_KEYS.has(k)) continue
      if (Array.isArray(v)) {
        for (const child of v) if (isNode(child)) visit(child, k, node)
      } else if (isNode(v)) visit(v, k, node)
    }
  }
  visit(parsed.program as unknown as Node, 'program', null)
  return findings.sort((a, b) => a.line - b.line || a.col - b.col)
}
```

```ts
import { basename } from 'node:path'
import { parseSync } from 'oxc-parser'

// Naming discipline (A0+A1 spec §3.3): kebab-case file names, and role suffixes that match what the file
// exports, in both directions. Replaces automata-template's S_/C_/M_ prefixes.

export type StyleRule = 'file-name' | 'role-suffix' | 'role-mismatch' | 'role-missing' | 'parse-error'

export interface StyleFinding {
  readonly file: string
  readonly rule: StyleRule
  readonly message: string
}

export const ROLES: ReadonlySet<string> = new Set([
  'component',
  'system',
  'command',
  'event',
  'resource',
  'plugin',
  'manager',
  'schema',
  'migration',
])

/** define* factory -> the role suffix its exported results require. */
const DEFINE_ROLE: Readonly<Record<string, string>> = {
  defineComponent: 'component',
  defineSystem: 'system',
  defineCommand: 'command',
  defineEvent: 'event',
  defineResource: 'resource',
  definePlugin: 'plugin',
}
const FACTORY_FOR: Readonly<Record<string, string>> = Object.fromEntries(
  Object.entries(DEFINE_ROLE).map(([fn, role]) => [role, fn]),
)

const NAME_RE = /^([a-z0-9]+(?:-[a-z0-9]+)*)(?:\.([a-z]+))?\.ts$/

type Node = { type: string; [k: string]: unknown }

/** Factory names of every `export const X = defineY(...)` / `export default defineY(...)` in the file. */
function exportedFactories(program: Node): string[] {
  const out: string[] = []
  const factoryOf = (init: unknown): string | undefined => {
    const call = init as Node | null
    if (call?.type !== 'CallExpression') return undefined
    const callee = call.callee as Node & { name?: string }
    return callee.type === 'Identifier' && callee.name && DEFINE_ROLE[callee.name] ? callee.name : undefined
  }
  for (const stmt of program.body as Node[]) {
    if (stmt.type === 'ExportNamedDeclaration') {
      const decl = stmt.declaration as Node | null
      if (decl?.type === 'VariableDeclaration') {
        for (const d of decl.declarations as Node[]) {
          const f = factoryOf(d.init)
          if (f) out.push(f)
        }
      }
    } else if (stmt.type === 'ExportDefaultDeclaration') {
      const f = factoryOf(stmt.declaration)
      if (f) out.push(f)
    }
  }
  return out
}

export function checkFile(file: string, code: string): StyleFinding[] {
  const name = basename(file)
  const finding = (rule: StyleRule, message: string): StyleFinding[] => [{ file, rule, message }]
  if (name === 'index.ts') return []
  const m = NAME_RE.exec(name)
  if (!m)
    return finding('file-name', `"${name}" must be kebab-case, optionally with a role suffix (name.role.ts)`)
  const role = m[2]
  if (role !== undefined && !ROLES.has(role))
    return finding('file-name', `"${name}" has unknown role "${role}"`)

  const parsed = parseSync(file, code)
  if (parsed.errors.length > 0) return finding('parse-error', parsed.errors.map((e) => e.message).join('; '))
  const factories = exportedFactories(parsed.program as unknown as Node)

  if (role === undefined) {
    const first = factories[0]
    if (first)
      return finding(
        'role-suffix',
        `exports a ${first} result, so the file must be named *.${DEFINE_ROLE[first]}.ts`,
      )
    return []
  }
  const factory = FACTORY_FOR[role]
  if (factory === undefined) return [] // manager, schema, migration: no define* factory to match
  if (factories.some((f) => f !== factory)) {
    return finding('role-mismatch', `a *.${role}.ts file may only export ${factory} results`)
  }
  if (!factories.includes(factory))
    return finding('role-missing', `a *.${role}.ts file must export at least one ${factory} result`)
  return []
}
```
