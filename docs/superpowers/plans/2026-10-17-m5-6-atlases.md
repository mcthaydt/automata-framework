## Contract

### `packages/content/src/assets/atlas-pack.ts` (create)

```ts
export const ATLAS_PAGE_MAX = 2048 // WebGL2's guaranteed MAX_TEXTURE_SIZE
export const ATLAS_PADDING = 1
export const ATLAS_EXTRUDE = 1
export interface FrameSize { readonly name: string; readonly width: number; readonly height: number }
export interface Placement { readonly name: string; readonly page: number; readonly x: number; readonly y: number; readonly width: number; readonly height: number }
export interface PackedAtlas { readonly pageSizes: readonly number[]; readonly placements: readonly Placement[] }
/** Throws `AtlasFrameTooLarge` for a frame that cannot fit a page with its extrusion. */
export function packFrames(frames: readonly FrameSize[]): PackedAtlas
```

**Algorithm.** Frames are sorted by name, in code-unit order. They are placed on shelves, left to right:
- Each cell is the frame plus `ATLAS_EXTRUDE` on every side.
- Cells are `ATLAS_PADDING` apart, and a page edge is `ATLAS_PADDING` from the first cell.
- A shelf's height is its tallest cell.

The page is the smallest power-of-two square, at most 2048, that holds every frame on one page. If none does, frames fill 2048 pages in order. `x` and `y` are the frame's own pixels, inside the extrusion.

### `packages/content/src/assets/atlas-image.ts` (create)

```ts
export interface Rgba { readonly width: number; readonly height: number; readonly data: Uint8Array }
export function decodePng(bytes: Uint8Array): Rgba // throws on a file that is not a PNG
export function encodePng(image: Rgba): Uint8Array // pngjs, fixed options: the same pixels give the same bytes
/** Draws each frame at its placement, and repeats its edge pixels into the extrusion. */
export function composePage(size: number, placements: readonly Placement[], frames: ReadonlyMap<string, Rgba>): Rgba
export function spritesheetJson(page: number, size: number, image: string, placements: readonly Placement[]): string
```

`spritesheetJson` writes Pixi's `Spritesheet` data: `frames.<name>` with `frame`, `rotated: false`, `trimmed: false`, `spriteSourceSize` and `sourceSize`; and `meta` with `image`, `format: "RGBA8888"`, `size` and `scale: 1`. Keys are in a fixed order, so the text is stable.

### `packages/content/src/assets/build-atlases.ts` (create)

```ts
export interface AtlasOutputs { readonly files: ReadonlyMap<string, Uint8Array> } // `<atlas>-<page>.png` and `.json`
export function buildAtlases(root: string): Effect.Effect<AtlasOutputs, ContentCompileFailed>
```

It reads `content/atlases.toml` and each folder's `*.png`, sorted. The frame name is the file name without `.png`.

**Failures,** each a `Diagnostic`, all reported together:
- a file that is not a PNG (`invalidAsset`);
- a frame larger than a page (`invalidAsset`);
- when the game declares `content/palette.toml`, an off-palette pixel (`offPalette`), naming the file, `x,y` and the colour.

Without a declared palette nothing is checked. The default Endesga 64 is the renderer's, not an authoring rule (§4.7: "when the game declares a palette").

`DiagnosticCode` gains `invalidAsset` and `offPalette` (additive).

### CLI

`automata-content assets` builds the atlases and writes them to `<outDir>/atlases/` (default `content/generated/atlases/`). Its exit codes are the CLI's: 0 for clean, 1 for problems, 2 for usage or write errors. `check --verify-artifact` does not cover atlases in M5.6 (the follow-up row above).

### Package entry

The `@mcthaydt/automata-content/assets` subpath exports `buildAtlases`, `packFrames` and the types. It is not the root entry, so `pngjs` stays out of any browser graph. It is added to the publish exports and the tsdown entries.

### `packages/render-pixi/src/views/sprite-view.ts` (modify; additive)

```ts
export interface SpriteViewOptions {
  // anchor, frames (DX.2b)
  /** A frame of a packed atlas: `source` is the atlas page's Spritesheet JSON url, `frame` its frame name (M5.6). */
  readonly frame?: string | undefined
}
```

With `frame`, `Assets.load(url)` resolves to a `Spritesheet`, and the view shows `textures[frame]`. A missing name is reported with `reportError` and the sprite stays empty, the same policy as a failed url. `frames` and `frame` together are a defect; the factory throws.
