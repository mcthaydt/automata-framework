Per editor, the first and last stops are asserted. *Fails first:* test missing; fixes (tabindex, order) follow what fails.
4. **Undo audit** `Suite.levels.dom.test.ts` additions (jsdom, memory workspace): (i) Levels 2D: place an entity, shell Undo, `workspace.read` returns the starting text byte for byte; Redo returns the edit; (ii) Levels 3D: the same for a sector edit; (iii) a workspace that refuses the write (read-only) leaves the file as it was and shows the refusal for both editors. 5. **Tuner WebKit iPad journey** `tuner.journey.test.ts` (modelled on `studio.journey.test.ts`: `arrived()`, `createPointers`, `IPAD_PROFILES`): a real-pointer drag of a slider is one undo step, a typed value past its bound is refused with the bound named, and the iPad turns in the middle of a drag with no remount (EDS-x, Tuner half).
