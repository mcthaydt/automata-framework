## Decisions (for the Owner's veto; defaults taken)

1. **The generator lives in `@mcthaydt/automata-content/locale`.** It turns a catalog into the `xx-long` catalog, and content owns the catalogs and their Paraglide compile (spec §9), so a game (and `automata check`, PRODUCT.L4) makes its `xx-long` locale there. `runtime/src/locale` cannot own it: `runtime` depends on `ui`, so `ui`'s tests could not import it without a cycle. `ui` takes `content` as a dev dependency for its layout tests only.
2. **Brackets are `⟦ ⟧`, as Ruken's.** They never occur in real copy, so `hasRawText` can tell a pseudo-localized span from English that skipped the catalog; ASCII `[ ]` can.
3. **Every contract runs twice, in `en` and in `xx-long`, with every variant** (rest, keyboard, Ruken's strip on either side, TV scale) and the same sizes as the English run (the reference sizes, 780×270 among them, and the tight sizes where the English run has them). The xx-long run also fails on any visible text that is not in xx-long (`hasRawText`), outside an element in its own `lang` (the language picker's endonyms), so a fixture or primitive that skips the locale cannot pass vacuously.
4. **Fixtures take a `locale` prop** (`'en'`, the default, or `'xx-long'`) and say every word through `say(locale, text)` from `src/testing/locale-fixture.ts`. That module imports `content`, which a game does not install with `ui`, so the published build strips it like the `*Fixture.svelte` components: `finishSvelteDist` drops `*-fixture.js` and `*-fixture.d.ts` (tooling/release).
5. **No screenshot baselines.** `ui`'s layout project asserts geometry; it has no screenshot goldens, so this plan writes none. Any primitive whose CSS this plan changes is listed under Owner gates for visual acceptance, with before/after captures in `docs/evidence/owner-visual/2026-10-30-product-l3a/`.
6. **The extra length is spread over the words (changed from Ruken, step 6).** Ruken puts it all in one run of `·` at the end: a 1,000-character message ended in a 400-character "word", and the first xx-long run failed ErrorPanel's long message on it (`error-panel-message scrolls sideways by 1482px`) and the Dialog's paragraph at TV scale, which is no language's behavior. Each word now carries its share right after it, so a message keeps its break opportunities; total length is still at least 40% more.
7. **`checkLayout` gains two checks (a published contract change, `ui/testing`).** The spec's "Clipping, overlap or a hidden action fails" had no check for clipping across a scroll region or for words spilling out of a control, so the xx-long run passed Settings with its options cut at the list's side and a Toggle's state word running past the toggle. Added: (a) *a control cut at the side of the scroll region it scrolls in* (a radio or checkbox judged by its label; a `position: fixed` control escapes the region); (b) *a control's words run past its edge* (only words as drawn: a box inside the control that clips on purpose, such as SaveSlots' two-line clamp, a `clip-path` visually hidden name and `visibility: hidden` text do not count). A first version of (a) compared `scrollWidth` and failed the touch overlay's invisible 24 px sticky margin with the keyboard up, in English; it was replaced by the control-based check before commit. A game's own screens get both checks through `@mcthaydt/automata-ui/testing`.
8. **The level-grid fixture's tiles are what a game with worded tiles would build** (`PrimitivesFixture` `paged-grid`): `minTile={64}`, three lines of a long language, and `overflow-wrap: anywhere` on the tile. PagedGrid is not at fault: it sizes tiles to the game's `minTile` (default 44, a target) and draws the game's `item` snippet; with the keyboard up at 360x640 a 44 px tile could not hold "Level 12" broken over three lines in xx-long. This changes the English captures of the fixture (6 of 525, listed in the evidence README). A theme-wide `overflow-wrap: anywhere` on `.af-control` was tried first and dropped: it let the corner row's Mute break mid-word in English at 360x640 TV scale (a `1fr` track sized by the smaller min-content), a visible English regression.
