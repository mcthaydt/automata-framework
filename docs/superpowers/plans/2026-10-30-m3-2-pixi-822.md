## Why

`@pixi/3d` 0.1.0-beta.2 (vendored in `vendor/pixi-3d/`) declares the peer `pixi.js` `^8.22.0`; core pins 8.21.0. The 3D runtime (M3.4 and on) cannot install against core until core moves. The spec makes the bump its own task with every gate (risk table: "The 8.22 bump changes 2D behavior"), before any 3D code depends on it.

## Decisions

- **8.22.0 exactly** (npm latest, the `@pixi/3d` peer floor). No other dependency moves.
- **Everything that names the version moves with the pins**, as in the zod 4.6.6 bump (QB.1e): every manifest that pins `pixi.js`, `pnpm-lock.yaml` (by `pnpm install`, never by hand), `packages/cli/src/create-game.ts` (a new game's `pixi.js`), the vendor labels in `packages/cli/src/check/no-eval-allowlist.ts` (after checking the 8.22 bundle against them), `docs/versions.md` and `docs/stack.md` (generated, `pnpm docs:stack`). Not changed: old plans, specs and spike reports, and `packages/editor-2d/.../floorfifty-stage/testing/PROVENANCE.md`, which records the version its goldens were computed on (history).
- **A test ties the scaffold to `docs/versions.md`.** Nothing failed when `create-game.ts` drifted from the pins; a new `create-game.test.ts` case reads `docs/versions.md` and checks every exact pin the scaffold writes. It is the failing test for the scaffold change.
- **S7-Q6 filter-stack guard:** AF carries no equivalent of FloorFifty's `filter-stack-guard.ts` (checked with a grep of `packages/`, `games/`, `examples/` and `tooling/`). The answer is recorded from the 8.21.0 → 8.22.0 diff of Pixi's filter code and its release notes, plus the gates below; the guard is extracted only if the crash still reproduces on 8.22 (spec §4.5).
- **No changeset for the private packages** (`render-pixi`, `game`, the umbrella, `cli`); a patch changeset for each published package whose manifest changes.

## Files

- **Modify:** every `package.json` that pins `pixi.js` (`packages/{automata,game,render-pixi}`, `tooling/frame-budget`, `examples`, `examples/physics/bodies-2d`, `games/emberwick`); `pnpm-lock.yaml`; `packages/cli/src/create-game.ts`; `packages/cli/src/create-game.test.ts`; `packages/cli/src/check/no-eval-allowlist.ts` (labels and comment only); `docs/versions.md`; `docs/stack.md`; this plan.
- **Create:** `.changeset/pixi-8-22.md` only if a published package's manifest changes.
