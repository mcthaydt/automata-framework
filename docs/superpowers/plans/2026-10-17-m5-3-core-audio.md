## Contract

```ts
// runtime/src/audio/audio-buses.schema.ts
export const AUDIO_BUS_NAMES: readonly ['master', 'music', 'sfx', 'ui', 'voice']

// runtime/src/audio/audio.manager.ts
export interface Audio {
  readonly unlocked: Subscribable.Subscribable<boolean>
  sound(alias: string, options?: { bus?: AudioBusName; gain?: number; rate?: number }): void
  music(alias: string, options?: { fromSeconds?: number; loop?: { start: number; end: number } }): Effect.Effect<void, AudioDecodeFailed | AssetLoadFailed>
  stopMusic(fadeSeconds?: number): void
  duck(bus: AudioBusName, amount: number, seconds: number): void
  setMuted(muted: boolean): void
}
export const Audio: Context.Tag<Audio, Audio>
export interface AudioOptions {
  readonly createContext?: () => AudioContextLike // default: new AudioContext()
  readonly window?: Pick<Window, 'addEventListener' | 'removeEventListener'>
  readonly document?: Pick<Document, 'visibilityState' | 'addEventListener' | 'removeEventListener'>
  readonly muteUnfocused?: boolean // FloorFifty's setting; master only
  readonly fetch?: typeof fetch // a file not in Assets (an example's own URL)
}
export const makeAudio: (options?: AudioOptions) => Effect.Effect<Audio & AudioBuses, never, Hosting | Assets | PresentationBus | Scope.Scope>
export const AudioLive: Layer.Layer<Audio | AudioBuses, never, Hosting | Assets | PresentationBus | Scope.Scope>

// runtime/src/audio/audio-error.ts (the TaggedErrorClass pattern of boot-error.ts)
export class AudioDecodeFailed { readonly _tag: 'AudioDecodeFailed'; readonly alias: string; readonly cause: unknown }

// runtime/src/presentation/presentation-bus.manager.ts, RuntimeFacts gains:
'audio.unlocked': {}
'audio.unavailable': { readonly reason: string }
'audio.decode.failed': { readonly alias: string; readonly reason: string }

// game/src/define-game.ts, GameSpec gains:
readonly sounds?: Readonly<Record<string, string | { readonly alias: string; readonly bus?: AudioBusName; readonly gain?: number }>>
// key: a sim event's type (`defineEvent`'s id); value: the asset path to play on the sfx bus when the event fires
```

**The graph:**
- each bus has a player gain node, then a duck gain node of its own, then goes to `master`;
- `master` is the player's master gain, multiplied by the host's `gain`, by the mute and by unfocused-mute, then the destination;
- `AudioBuses.input(bus)` is the bus's player gain node. `input('master')` is the master node, so a source there skips the bus gains but not the host's;
- `AudioBuses.input` before unlock builds nothing. It throws, saying audio is not unlocked; an extension waits on `unlocked`.

**An alias is an asset path.** The decoder reads `Assets.get(path)` first. A file the game's screens did not preload is fetched with the seam's `fetch`; a failed fetch is `AssetLoadFailed`. Each alias is decoded once and cached.

## Deviations for review

- `AudioLive` does not need `Settings`. The player's levels and `muteUnfocused` come from the Audio section in M5.4, which calls `setGain`, `setMuted` and the option. Until then a game passes `muteUnfocused` in `AudioOptions`.
- `AudioLive` needs `PresentationBus`, for the three facts, which §4.6's signature leaves out.
- An alias is the asset path. A file that is not preloaded is fetched, as `sprite(url)` loads a texture.
- `sounds` in `defineGame` is new design. §4.6 says sim events reach audio as presentation-bus facts; the map is the game lane's way to say which.
- Sleep follows FloorFifty: lifecycle `background` sleeps only when its reasons include `hidden`. §4.6 says "background", which would also silence a blurred window; `muteUnfocused` covers that case instead.
