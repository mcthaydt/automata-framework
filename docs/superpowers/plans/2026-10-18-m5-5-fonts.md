## Contract

### `content/fonts.toml` (`packages/content/src/assets/fonts.schema.ts`, create)

```toml
[font.pixel]
file = "fonts/pixelify-sans-latin-400.woff2"   # relative to the project root, committed by the game
sha256 = "…"                                    # of the file's bytes, lower-case hex
license = "OFL-1.1"
locales = ["en", "fr"]                          # content languages this font serves
```

Font names are like `pixel` or `ui-cjk`. `locales` is non-empty. Each locale must be a language the content compiles: an unknown one is `unknownReference` at `font.<name>.locales.<i>`.

### `CompiledContent.messageLocations` (`compile-content.ts`, modify; additive)

```ts
export interface MessageLocation { readonly file: string; readonly line: number; readonly column: number }
/** Where each language's message is written: the source TOML's text, or the translation's key. */
readonly messageLocations: ReadonlyMap<string, ReadonlyMap<string, MessageLocation>>
```

### `packages/content/src/assets/font-subset.ts` (create)

```ts
/** `subset-font` to woff2 with fixed options: the same source and characters give the same bytes (G-a). */
export function subsetWoff2(source: Uint8Array, characters: ReadonlySet<string>): Promise<Uint8Array>
/** Whether a font file (any format fontkit reads) has a glyph for each character. */
export function fontCoverage(font: Uint8Array): (character: string) => boolean
```

The characters are sorted by code point before they are joined, so the order of a set never reaches the subsetter.

### `packages/content/src/assets/build-fonts.ts` (create)

```ts
export interface FontOutputs { readonly files: ReadonlyMap<string, Uint8Array> } // `<font>-<locale>-<hash8>.woff2`, `fonts.json`
export function buildFonts(options: ContentOptions): Effect.Effect<FontOutputs, ContentCompileFailed | InvalidContentConfig | ContentWriteFailed>
```

1. Compile the content, for `catalogs` and `messageLocations`. A compile failure is the build's failure.
2. Read `content/fonts.toml`. Without it, there is nothing to build.
3. For each font, sorted by name:
   - read its file;
   - refuse a sha256 that differs (`invalidAsset` at `font.<name>.sha256`: "sha256 X is not the recorded Y");
   - for each locale, cut the subset to `localeCharacters(catalog)`.
4. The output name is `<font>-<locale>-<first 8 hex of the subset's sha256>.woff2`.
5. **Glyph gate (G-b, L-e).** Each locale's subsets together must cover every character of every message in that locale. A game may stack a Latin face and a CJK face, as FloorFifty does, so coverage is the union of the locale's subsets.
   - Control characters (`\p{Cc}`, such as a newline) draw no glyph and are not checked.
   - A message with missing characters fails `missingGlyph` at its `MessageLocation`, with the key path being the message key. The diagnostic names each missing code point once, as `U+65E5 "日"`, and the locale.
   - A language that no font serves is not checked.
6. `fonts.json`: `{ "<font>": { "<locale>": "<file>" } }`, with keys sorted and the canonical JSON text.

All problems are reported together, as the atlas build does. `DiagnosticCode` gains `missingGlyph` (additive).

### CLI

`automata-content assets` builds the atlases into `<outDir>/atlases/`, as it does now, and the fonts into `<outDir>/fonts/`.
- Nothing is written when either build has a problem.
- The output line is `atlases N files, fonts M files`.

### Package entry

`@mcthaydt/automata-content/assets` adds `buildFonts`, `FontOutputs`, `subsetWoff2` and `fontCoverage`. `MessageLocation` is exported from the root, next to `CompiledContent`.
