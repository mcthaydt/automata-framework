## What it is

A suite editor `tuner` (the id `content/editors.toml` rows name) over one file, `content/tuning.toml`, whose top level is `NAME = value` rows (UPPER_SNAKE). A tunable is one of:

| Spelling in the file | Kind | Bounds |
| --- | --- | --- |
| `NAME = 5`, `NAME = 0.25` | number (`int` when written without a fraction, else `float`) | from `tuning-meta.json` (the compiler's output, read with `workspace.generated`) when the game declares tunables in code; otherwise none: a number box with no slider |
| `NAME = { value = 5, min = 1, max = 9, step = 1 }` | number | inline (authored) |
| `NAME = true`, `NAME = "text"` | toggle, text field | none |
| anything else (a table, an array) | not editable here | shown as "Ask only" |

Unit and note come from the row's trailing or preceding TOML comment (EDS-D18: `tuning.toml` has no unit or note field): the note is the comment text; the unit is a trailing token such as `px/s`, `s`, `ticks` when the comment is `# <number> <unit>` shaped, else none.

Directly: drag the slider (one drag is one undo step: the kit's `start`/`update`/`commit`/`cancel` phases through one history transaction), type in the number box, tap a toggle, edit a text field. A value outside the bounds, a fraction for an `int`, or a non-number is **refused before the write** with the bound named; nothing is written (EDS-c). A lock (a key path in the session's set, never in a file) makes the Tuner's own controls refuse that tunable and makes an Ask proposal that changes it refuse with the key (EDS-d).

## States

No tuning file (offer: "Create tuning.toml" writes an empty file with a one-line header through the port, one undo step); a file that does not parse (opens read-only with the parser's line and column in the panel); code-owned bounds unavailable (the generated file is absent: "Run checks to read bounds", number boxes only); a tunable that is locked; out of bounds (refusal sentence, kept until the next action); not writable (the port's reason).

## Decisions for the Owner's veto (agent defaults)

- Locks live in the session (EDS-D18) and also guard the Tuner's own controls, not only Ask.
- An `int` is a bare number written without a fraction, or an inline table whose `value` and `step` are whole; `float` otherwise.
- Bounds validation is a small local check, not a dependency on `@mcthaydt/automata-content` (the compiler still judges the file as the `content` check).
- The Fairness tab, groups by scene and the `systems` source are absent (EDS.4b).
