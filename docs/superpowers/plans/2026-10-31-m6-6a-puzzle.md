## Scope

In: `packages/puzzle` (`@mcthaydt/automata-puzzle`, private, M6-D3):
- the `puzzle` content schema, the shape of the source's `PuzzleDef`, unchanged;
- the `Value` and `Cond` types and schemas, exported for narrative and systems;
- the `puzzle-state` resource (facts as a sorted record, items, seen actions);
- the `verb` command (`at`, `held`, `pair`, `code`, `point`), with the first matching action's effects applied in
  order;
- the `puzzle.said`, `puzzle.gave` and `puzzle.goal` events;
- the cross-extension effects as events (`noise`, `cutscene`, `dialogue`, `exit`, `checkpoint`, `keypad`);
- `hooks.facts`, to map facts to a game's own fields;
- `{ call }`, naming a game system registered with `defineSystem`, which runs on the step it is called;
- the compile-time checks;
- a one-off converter for the four scenes;
- a four-engine golden;
- P-c's engine half.

Out: the solver, softlocks, hints and the pipeline commands (M6.6b), route tests and the 16 routes (M6.6c), and lines
and item names as presentation text. `puzzle.said` carries the line key, and the game's locale shows it, so
`PuzzleText` stays the game's.

## Compile-time checks (§4.5, §6)

Each is reported at its path, so the content compile names the file and line:
- an action whose `use` names an undeclared item;
- an effect `give` or `take` of an undeclared item;
- a `fallback` line key that is not a string;
- a `noise` at an undeclared hotspot;
- a `cutscene`, `dialogue` or `noise` effect whose extension is not registered (the content schema takes the
  registered extension names; a game builds it with `puzzleContent({ extensions })`);
- a `{ call }` the game did not declare in `calls`.

## Decisions for the Owner's veto

- **P6-D1:** M6.6a's code does not wait for M6.5. The interpreter needs neither nav nor sectors; the walk-then-verb flow
  is the game's.
- **P6-D2:** `{ call }` is an event a named game system handles on the same step, not a function the sim calls back.
  It keeps the sim's systems the only code that changes state (law 1). An undeclared call name is a content error.
- **P6-D3:** `puzzle.said` carries line keys and item ids, not text. Titles, item names and line text are the game's
  presentation (locale), so `PuzzleText` does not come across.
- **P6-D4:** noise positions come from a `hotspots` record in the puzzle content instead of a `hotspot(id)` hook.
