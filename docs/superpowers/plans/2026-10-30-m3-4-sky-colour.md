# M3.4: the sky colour behind 3D scenes (TDD plan)

**Status:** drafted 2026-10-30; approved by the Owner 2026-10-30 (the task: "behind 3D scenes, render-pixi3d draws black instead of the sky or background colour").

**Branch:** `claude/3d-m3-4a-render3d` (PR #241), the lowest branch where `Pixi3dOptions.backgroundColor` and the `View3D` both exist; merged up into `claude/3d-m3-4b-camera` (#245) → `claude/3d-m3-4c-occluders` (#249), and into `claude/3d-m3-4d-light` (#247).

## Root cause

The 3D view never draws a sky. `View3D.background` is `null` by default, so where no mesh covers the field the composite texture stays transparent and the letterbox's backdrop shows through: `LetterboxFrame`'s field fill, `DEFAULT_FIELD_COLOR` = `0x000000`. `Pixi3dOptions.backgroundColor` (from `PixiRendererOptions`) only sets the Pixi app's clear colour, which that field covers inside the letterbox, so it has no visible effect. `view.environment`'s `skyColor` in the examples is the hemisphere *light*, not a background. M3.4a's finding "the View3D clears the whole canvas" was this black field, not a clear: a readback shows the composite's empty pixels are `(0, 0, 0, 0)` and the bars keep `barColor`.

## Design

- `Pixi3dOptions.backgroundColor`, when given, is the sky: in a letterbox the renderer puts a 2D fill of the view's rect in `stage.world` under the `View3D`, so the view's empty pixels show it. Pixi's 2D draws it as given on both backends, so WebGL2 and WebGPU stay at parity. (The first version set `view.background` to a flat `Hemisphere`; `@pixi/3d`'s background pass lifts dark colours, `0x020c0c` drawing as `0x091414`, so a fog's dark far colour could not be matched. See the log.) Without a letterbox the app's clear colour, which is `backgroundColor`, is already the sky. A `scene` hook may still set `view.background` over it.
- The sky is drawn inside the 3D view only: the letterbox bars keep `barColor` and the portrait backdrop keeps the field colour.
- M3.4d (on merge): with fog, the sky is the colour fully fogged pixels reach on screen, so fogged walls fade into it and no view shows a seam at the far side (spec §4.2 S7-Q10, "fog or a wall closes every view's far side").
- The examples that set a sky light (`render3d-meshes`, `render3d-angled-camera`) pass `backgroundColor: 0xc7dcd0`, their hemisphere's `skyColor`.
