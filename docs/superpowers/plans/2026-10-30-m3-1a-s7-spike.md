## Decisions

- **Outside the workspace.** `spikes/s7-pixi3d` is its own package (`pnpm install --ignore-workspace`, its own lockfile), so `pixi.js` 8.22.0, which `@pixi/3d`'s peer needs, does not reach core before M3.2. `pnpm-workspace.yaml` is unchanged; knip ignores `spikes/**`.
- **Real seams, not copies.** The page imports render-pixi's `no-eval`, `createPixiRenderer` and `RenderDeltaConsumer` from `packages/render-pixi/src` through Vite aliases; `resolve.dedupe` gives them the spike's `pixi.js` 8.22.0. The runtime is aliased to the two values the renderer imports (`RendererUnavailable`, the runtime's own class, and `DEFAULT_QUALITY`) and the ui package to `form-factor.ts`, so the page does not bundle Svelte.
- **Measured where it can be.** Q1, Q5 (runtime half), Q7 and S7-g run in Chromium, WebKit and Firefox headless in this container (software WebGL2, named in the results). Q8 and Q9 are first Node numbers, labelled as not the phone profile. Q2, Q3, Q4, Q10 and the phone numbers are M3.1b's (GPU runner).
- **The pixi.js 8.22 bump (S7-Q6) is never committed here**; M3.2 owns it.
