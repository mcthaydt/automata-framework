# What the site is missing, from a Ritmo comparison

> Written 2026-10-25. Ritmo's site ([ritmo.typeonce.dev](https://ritmo.typeonce.dev/)) was read through a page summarizer, so wording and detail may be off. Our side was checked against this checkout (`5cd8fd4`): the footer, header, `/ai`, the homepage and `static/llms.txt`. The framework-side companion is `docs/research/2026-10-25-ritmo-comparison.md` in `mcthaydt/automata-framework`.

These are gaps and candidates, not commitments. Follow the rule in [cut claims](2026-10-14-cut-claims.md): publish a statement only when it has proof, and keep instruction loading separate from enforcement.

## Where we are ahead

Keep these when making changes:

- A playable starter on the homepage and a worked change with recorded proof.
- Migration guides from Unity, Godot, Unreal, GameMaker and web.
- A cut-claims ledger and evidence-backed `/proof`.
- Accessibility and performance gates (axe, Lighthouse).
- `llms.txt` and `llms-full.txt` (both also exist on Ritmo's site, so this is parity, not an advantage).

## Suggested order

1. Gap 5: verify or formally drop the agent install commands. It is already an open ledger item and needs no framework work.
2. Gap 6 and gap 7: content only, from existing specs.
3. Gaps 1, 3 and 4 wait on framework decisions about typed access, a minimal example and debugging tools. Raise them with the framework first.
4. Gap 2 follows DX.11.
