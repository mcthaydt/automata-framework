# c8 Lit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task (no
> subagents in this project). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A painted figure in an AF scene is lit by its room on WebGL and WebGPU, hides texel by texel under WebGPU, and
paints the same cell on x64 and arm64.

**Architecture:** FigureBuilder (FB) gains three things: a tie rule in its rasteriser, a pure `lightSprite` that lights a
painted cell in whole DUEL steps, and a WGSL stage that writes a depth per texel. AF's character kit reads the room's light
through `SceneLight.tint`, lights each cell on the CPU through FB's function, caches it, and draws it on FB's `CellSprite`
as it draws any cell. Nothing in `packages/3d` changes.

**Tech Stack:** TypeScript; FigureBuilder (git submodule `vendor/FigureBuilder`, `STAGE_VERSION` 1, Vitest 5,
`vite-node`); PixiJS 8.22 with `@pixi/3d` 0.1.0-beta.2; AF's Vitest 5 Node and browser projects; Playwright 1.63.

**Spec:** [`2026-11-11-c8-lit-spec.md`](2026-11-11-c8-lit-spec.md). Read it first: sections 5 to 7 hold the rules and the
evidence this plan argues from. FB's contract is `vendor/FigureBuilder/docs/contract.md`.

- Every lit colour is a DUEL colour. A texel moves along its own row in whole steps; the only way off a row is FB's
  `grade`. Ink, `RAMP_OUTLINE` and a row's step 0 never move.
- Without `lighting`, or with `lit: false`, a painted figure's frame is byte-identical to today's.
- Budget: eight D2 figures lit, at most 2 ms a frame at the median and 6 ms at the worst frame.
- FB's four goldens (`base`, `lit`, `actors`, `sprites`) must not move on x64. If one does, stop and show the coordinator.
- Never skip, loosen or re-record per platform. A WebGPU case skips, in words, only where the browser grants no adapter.

- AF: a feature imports only itself and `shared/`; tests import `#src/…`; `.test.ts`; at most 600 lines a file; kebab-case;

## Review Focus

Inputs the spec implies and no happy-path test meets. Each has its test in the task named.

1. **A room with no light at the figure** (`tint` returns 0, 0, 0; a figure outside the level): `flatSteps` clamps to −3,
   no `NaN`, no lamp, the figure is dark, not black and not thrown on. Tasks F2 and A2.
2. **A lamp switched while a figure stands still**: the painted cell's key is unchanged, the light is not; the lit cell
   must change on the next frame. Task A3.
3. **A cell with no normals** (a held item, a flat material; `normals` alpha 0 everywhere) under a strong side lamp: no
   form, no rim from a mean of nothing, no division by zero. Task F2.
4. **The renderer asked for WebGPU and got WebGL** (no adapter): the same lit bytes and per-texel depth as a WebGL
   renderer, no warning. Task A5.
5. **Density or figure size changing under a warm cache** (a view at D1 after D2): a lit cell of the old size is never
   shown. Task A3.

### Task F1: The rasteriser's tie rule

**Files:** modify `src/features/paint/raster.ts` (`rasterize`); create `tests/support/ulp.ts`,
`tests/features/paint/ulp.test.ts`.

**Interfaces:**
- Produces: `nudged<T>(seed: number, run: () => T): T` in `tests/support/ulp.ts`. It replaces `Math.sin`, `cos`, `tan`,
  `atan2`, `atan`, `asin`, `acos`, `exp`, `log`, `log2`, `pow` and `cbrt` for the length of `run`, each returning its true
  value moved one unit in the last place up (a quarter of calls), down (a quarter) or unchanged, by a 32-bit LCG
  (`s = s × 1664525 + 1013904223`) seeded with `seed`, and restores them in a `finally`. Zero and non-finite values pass
  through. `seed` 0 nudges nothing.

- [ ] **Step 1: Write the failing tests** in `tests/features/paint/ulp.test.ts`:

  - `'two coincident faces of one part: the one facing the camera wins, whichever is drawn first'`: build a `Soup` of two
    triangles covering the same three screen points, same part, group and material, normals `(0, 0, 1)` and `(0, 0, −1)`,
    depths equal, then the second a last bit nearer, then a last bit farther; in both draw orders (six cases). After
    `rasterize` into an 8 × 8 `gbuffer`, every covered sample's `normal` z is `1`.
  - `'faces of two parts at one depth: the first drawn keeps the sample'` (today's rule, pinned): the same with two part
    ids; the covered samples' `part` is the first triangle's.
  - `'the base pair paint the same cell whatever the last bit of the maths'`: for each of `BASE`'s two members, directions
    0 to 7, standing and at walk phase 0.25, D2: `expect(md5(nudged(seed, paint))).toBe(md5(paint()))` for seeds 1 to 40.
    A fresh `Figure` per paint (no cell cache across seeds).

- [ ] **Step 2: Run them.** `npx vitest run tests/features/paint/ulp.test.ts`. Expected: the first fails (a back face wins
  some cases). Record whether the third fails on `main`; it may pass (the base pair wear no garment), and then it is the
  guard, not the evidence. The evidence is AF's test in Task A2.

- [ ] **Step 3: Implement the rule in `rasterize`.** `const Q = 2 ** 20`; a sample's test depth is
  `Math.round((z + layerOffset) * Q)` against `Math.round(depth[k] * Q)`:
  - greater: the sample is taken (as today);
  - less: skipped;
  - equal, the same `part` as the texel holds, and this triangle's interpolated normal z greater than the stored one:
    taken;
  - equal otherwise: skipped (the first drawn keeps it).

  The stored `depth[k]` stays the unquantised `z`. The `LAYER` and `over` rule is untouched. Keep the inner loop
  allocation-free; the interpolated normal z is computed only on an equal depth.

- [ ] **Step 4: Run everything.** `npm test`. Expected: the three new tests pass and **all four goldens pass unchanged**.
  If a golden fails: stop. Write the failing cells' expected, actual and diff PNGs, send them to the coordinator, and wait.
- [ ] **Step 5: Measure the raster's cost.** Time `npm run render -- out` before and after (three runs each, the median).
  Put both numbers in the commit message. More than 5% slower: say so to the coordinator and carry on.
- [ ] **Step 6: Commit.** `fix(paint): two faces at one depth, the one facing the camera wins; depths compared on a micrometre grid`.
  The message says why: the arm64 flip in automata-framework's runway golden, traced to this test (the spec's section 7a).

- Produces, exported from `src/index.ts`:

```ts
export interface SpriteLamp { dir: V3; strength: number }
export interface SpriteStyle { threshold: number; rim: number; rimSide: number; stepRatio: number; down: number; up: number; chroma: number; tint: number }
export const SPRITE_STYLE: SpriteStyle = { threshold: 0.22, rim: 0.35, rimSide: 0.25, stepRatio: 1.17, down: -3, up: 2, chroma: 0.02, tint: 0.35 };
export interface SpriteLighting { flat: V3; lamps: SpriteLamp[]; exposure?: number; style?: SpriteStyle }
/** Whole DUEL steps for a light: clamp(round(ln(peak) / ln(stepRatio)), down, up); `down` for a peak of 0 or less. */
export function flatSteps(flat: V3, style?: SpriteStyle): number;
/** A painted cell lit as a sprite: a new RGBA cell. The spec's section 5a, rules 1 to 8, in that order. */
export function lightSprite(f: LitSource, L: SpriteLighting): Uint8ClampedArray;
```

  The tint (rule 7): `tint` is the flat light's colour at full value as a hex int; it applies when the flat light's OKLab
  chroma is over `style.chroma`; the amount is `Math.round(style.tint × 0.7 × 8) / 8`, `lightFigure`'s own quantising.

- [ ] **Step 1: Write the failing tests** in `sprite.test.ts`, on the base woman at direction 1, D2 (`new Figure(member(BASE[1].def, 2))`):

  - `'flatSteps: 1 is no step, 1.6 two up, 0.5 three down, 0 three down'`:
    `expect([1, 1.6, 0.5, 0, 1.17, 0.86].map(v => flatSteps([v, v, v]))).toEqual([0, 2, -3, -3, 1, -1])`.
  - `'a grey light of 1 with no lamps returns the painted cell'`: bytes equal `figure.painted`.
  - `'under a grey light every texel stays on its own row'`: for flat 0.5, 1 and 1.6 with a lamp `{ dir: [-1, 0, 0],
    strength: 1 }`: `onRow(out)[0] === onRow(in)[0]` for every filled texel.
  - `'ink, the outline and a row’s darkest step never move'`: every input texel that is `0x000000`, `RAMP_OUTLINE` or on
    step 0 is unchanged, under flat 1.6 and under flat 0.3.
  - `'a brighter room is whole steps up, a darker one whole steps down'`: with no lamps, for every moved texel,
    `onRow(out)[1] − onRow(in)[1]` is `flatSteps` clamped into 1…7.
  - `'a lamp from the left: texels facing left a step up, facing right a step down, the left edge rimmed'`: count texels
    whose normal x is under −0.5 and whose step rose, and over 0.5 and fell; both counts are over half their groups; a
    left silhouette texel (empty at `x − 1`) not otherwise never-stepped is a step up.
  - `'exposure takes whole steps off'`: `lightSprite(f, { flat: [1.6, 1.6, 1.6], lamps: [], exposure: 2 })` equals the
    flat-1 result.
  - `'a warm light tints through grade and stays in DUEL'`: flat `[1, 0.8, 0.55]`: every output colour is in `RAMPS`; at
    least one texel differs from the grey-light result.
  - `'a tiled cloth lights its ground and keeps its tile'` (a fixture member wearing a registered fabric, as
    `tests/features/lighting` already builds one): where `weave.on`, the output equals
    `tiled(lit ground, label, lo, hi)`.
  - Review Focus 1: `'no light at all: dark, finite, no throw'`: flat `[0, 0, 0]`, no lamps: every moved texel is at
    `max(1, s − 3)`; no `NaN` in the output.
  - Review Focus 3: `'a cell with no normals under a side lamp is lit flat'`: a `LitSource` whose `normals` are all zero,
    one strong side lamp: equals the same call with no lamps.
  - `'deterministic'`: two calls give equal bytes; the input buffers are unchanged.


  `roomLight`: the flat light is `tint(x, y + chest, z)`; the lean on each axis is the peak channel of `tint` with that
  axis's normal less the peak with its opposite; the resultant, quantised to sixteenths a component after normalising and
  turned by Ry(−azimuth), is the one lamp, its strength the resultant's length rounded to 0.1; under `floor` there is no
  lamp. The ring is the mean of `tint(x ± ring, y, z, up)` and `tint(x, y, z ± ring, up)`;
  `exposure = max(0, flatSteps(flat) − flatSteps(ring) − hot)`. `key` is
  `<flatSteps − exposure>|<tint in eighths, or ->|<dir x,y,z in sixteenths, or ->|<strength>`.

  `litCells().lit`: the unlit cell's key is `cellOf(figure).key`; the cache key is that plus `|` plus `light.key`; a hit
  returns the stored cell; a miss calls `lightSprite(figure, light.lighting)`, **copies nothing it does not own** (the
  lit buffer is new each miss; `painted`, `normals` and `depth` are the figure's and valid until its next draw, as the
  contract says), stores `cellOf(figure, lit)` and drops the oldest past the limit.

  `painter.paint` takes an optional `light: RoomLight | undefined` and returns `cells.lit(figure, light)` when given.
  `paintedFigure` reads the factory's fourth argument: with a `SceneLight` and `options.lit !== false`, each frame calls
  `roomLight((x, y, z, n) => light.tint(x, y, z, n), at, view.azimuth)`. `PaintedFigureOptions.lit?: boolean`.
