## Calls for the Owner

1. **The spec's veto defaults stand** until the Owner says otherwise, notably: tests in a `tests/` folder per package
   rather than one repository-wide folder (12.1), and the game id becomes `emberwick`
   (12.5). Two new ones were added: `tools` publishes the CLI (12.8), and the changeset checks stay on PRs (12.9).
2. **The old package names** (`@mcthaydt/automata-host`, `-runtime`, `-ui`, `-game`, `-render-pixi`, `-testing`,
   `-node`, `-ship`, `-cli`) stop getting releases. Marking them deprecated in GitHub Packages needs the registry
   credentials, so it is the Owner's step, if wanted at all.
3. **Real-device play on the iPad** stays the Owner's (spec section 1, item 2).
