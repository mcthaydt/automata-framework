# Site slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task
> (the Owner's rule: no subagents). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the website at automataframework.com in the approved look, with a page for the paid apps, deployable with
checked headers and launched only once Pixi 3D is public, with every package renamed to the `@automataframework` npm
scope in one final mechanical pass.

**Architecture:** Three parts in order. A and B change `site/` (and the 2D examples' colours) on top of the open stack,
using today's names. C is a table-driven codemod plus a guard test, run once from `main` after the stack merges, with a
recipe for any PR that lands later. D is the launch: the Owner's accounts, the first release, the deploy.

**Tech Stack:** SvelteKit 2.70.4, Svelte 5, Vite 8.3.3, `adapter-static`, Vitest, Playwright 1.63 (Chromium here;
WebKit and Firefox on the Mac runner), Cloudflare Pages with `wrangler`, changesets, Node 24.

**Spec:** [2026-11-08-site-spec.md](2026-11-08-site-spec.md). The audit it answers:
[2026-11-08-site-audit.md](2026-11-08-site-audit.md). The plan audit, whose fixes are in both:
[2026-11-08-site-plan-audit.md](2026-11-08-site-plan-audit.md).

## Global Constraints

- Corners `--edge-sm/md/lg` only; never `--radius*`, `--pill` or a fully rounded button. Colours and type from the
  editor kit's tokens (`packages/editor/src/shared/kit/tokens/tokens.json`).
- Touch targets at least 44 px, primary actions 48 px, at the six audit sizes (390 × 844, 844 × 390, 820 × 1180,
  1180 × 820, 1440 × 900, 900 × 1440). Never hide an action to make a picture fit.
- Every user-facing string passes the drunk grandma test (spec section 7) and gets a row in `docs/refactor/copy.md`.
- Templates appear only on the try-it page. The editors keep only essential features; this slice adds none to them.
- The contact and security address is `hello@automataframework.com`; the origin is `https://automataframework.com`.
- Pictures come from `site/scripts/take-pictures.ts`; numbers (sizes, budgets, counts) are measured, never typed.
- Tests import site code as `#src/…`; a source file (`.ts`, `.svelte`, `.css`) is at most 600 lines.
- Comments say why, never which plan or finding asked.
- No force-push, no amend of a pushed commit, no subagents. `pnpm format` before each commit; Conventional Commits.
- Parts A and B keep the names `@automata/*`; only Task 6 renames.
- Build the site with `pnpm exec turbo run build --filter=@automata/site` from the root: `cd site && pnpm build` fails on
  a fresh checkout because the API index needs the nine extensions built first (`site/turbo.json`).
- One lime primary per screen; Home's is the hero's "Make a game", so the demo's "Play it" is the white secondary.
- The web shows only the editors it keeps (spec R7); the try-it does not play a level (spec R8) unless the Owner adds it.
- Every task's commit also appends its entry to this plan's log and updates `docs/refactor/progress.md`.
- Nothing of AF is public before Pixi 3D is (spec D4): the site deploys only when `check:launch` passes, and that asks
  npmjs.org for `@pixi/3d`; no built file may carry Pixi 3D (the build's last step, `scan-closed-beta.ts`); no page
  shows the full suite or a 3D editor (R4, R7).
- Prices and places to buy come only from `site/src/features/app/app-offer.ts`; a place to buy with no link reads
  "Coming soon", never a button.

## Review Focus

1. **A hydration race on Home.** Home is prerendered and hydrates after the first paint; a press on "Play it" before
   hydration must still start the game (today's journey accepts a lost press and presses again). Task 2's e2e presses
   once, right after `goto(..., { waitUntil: 'commit' })`, with no retry.
2. **The command on a 390 px phone.** It must not wrap or cut mid-word without an ellipsis, and the copy button must
   copy the whole command. Task 1's `CodeBlock` test checks the copied text equals the full command at 390 px.
3. **A missing address under a nested path** (`/docs/nope/deeper`) must get the same `404.html`, styled and hydrated
   (SvelteKit's relative asset paths break there, so `paths.relative` is `false`). Task 4.1's e2e opens a nested missing
   address and checks the stylesheet loaded and a link works.
4. **Headers on a path two rules match** (a demo matches `/*` and `/demos/*`) must not repeat a header: Cloudflare
   joins repeats with a comma, and a doubled HSTS is ignored. Paths no rule names (`/llms.txt`,
   `/.well-known/security.txt`) still get the base set. Task 5.1's check walks every built file under Cloudflare's rule
   and then asks `wrangler pages dev` itself.
5. **A straggler PR after the rename.** Its names must not survive a merge, and its branch still holds the old codemod.
   Task 6.1's guard is part of `pnpm check`; the recipe takes main's codemod first and is rehearsed in Task 6.2 on a branch
   made before the rename.
