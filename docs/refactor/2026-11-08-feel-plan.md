# Feel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task (no
> subagents in this project). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring the built Feel editor in line with its spec: every field of `feel.toml`, the game's events, limit
words, and a stage that plays each change at once with the player's settings.

**Architecture:** `extensions/editors/src/features/feel` keeps its model (pure functions over `FeelContent` that return
`ContentEdit`s) and session. A new `feel-stage.ts` drives `@automata/feel`'s `createFeel` with given frame times, and
`FeelStage.svelte` draws its frames on a 2D canvas. `shared/game-events.ts` gathers event ids for Feel and Audio.

**Tech Stack:** Svelte 5 runes, Vitest 5 (jsdom, Testing Library), Zod 4, `@automata/feel`, `@automata/audio-synth`,
the kit's content documents and `History`.

**Spec:** [`2026-11-08-feel-spec.md`](2026-11-08-feel-spec.md), with the shared
[`2026-11-08-content-editors-spec.md`](2026-11-08-content-editors-spec.md).

## Global Constraints

- Code lives in `extensions/editors` (`@automata/editors`, private, no changeset). Core never imports it.
- A feature imports only itself and `shared/`; tests import `#src/…`; files at most 600 lines; kebab-case names.
- Every write goes through `ContentSession.change` (span-preserving edits, mtime guard, undo on refusal).
- The preview never writes the file. The game's simulation is never run.
- Copy passes the drunk grandma test; the words are the spec's section 4 table, verbatim.
- Touch targets at least 44 px, primary actions 48 px; design at 390×844 first.
- Failing test first; `pnpm format`, then the package's `test:unit` and `typecheck`, before each commit.

## Review Focus

1. **A pattern entry on the stage.** `player.*` plays with the event `player.example`; entries matching that also play.
   Test in Task 3.
2. **A choice back to its default.** "Everything" removes `target`; "Phone buzz" 0 removes `phone_ms`; an absent key set
   to a non-default inserts it. Test in Task 1.
3. **A file with a mistake.** The stage shows "Fix the file to play it." and plays nothing; nothing writes. Test in
   Task 4.
4. **No pad, no vibrate, no cue.** The stage says what it would do in words and throws nothing. Test in Task 3.
5. **A locale or cue the game lacks.** Kept, shown, and named ("The game has no word `hit` yet."). Test in Task 5.

### Task 3: The stage

**Files:**
- Create: `extensions/editors/src/features/feel/feel-stage.ts`, `extensions/editors/src/features/feel/FeelStage.svelte`
- Test: `extensions/editors/tests/unit/feel/feel-stage.test.ts`

**Interfaces:**
- Consumes: `createFeel`, `matches`, `FeelSettings`, `FeelFrame`, `Pulse` from `@automata/feel`.
- Produces: `stageEvent(on: string): string` (each `*` becomes `example`);
  `stageFrames(content: FeelContent, on: string, settings: FeelSettings, reduced: boolean, frameSeconds: number,
  count: number): FeelFrame[]` (hears one event at tick 0, subject entity 1, then draws `count` frames at tick 0);
  `interface StageOutputs { rumble(pulse: Pulse): boolean; cue(id: string): boolean }` (false when the device or game
  cannot) and `browserOutputs(play: (cue: string) => boolean): StageOutputs` (Gamepad `vibrationActuator`, else
  `navigator.vibrate(phoneMs ?? ms)`).
- `FeelStage.svelte` props: `content: FeelContent | undefined`, `on: string | undefined`, `settings: FeelSettings`,
  `reduced: boolean`, `outputs: StageOutputs`, `replay: number` (a change counter that restarts it).

- [ ] **Step 1: Write the failing tests.** For an entry `{ on: 'player.hit', camera: [{ shake: 1 }], visual: [{ flash:
  'white', frames: 2 }] }` at 1/60 s: frame 0 has a non-zero offset and a flash; frame 3 has no flash. With
  `reduceFlashing` no frame has a flash. With intensity 0 every offset is `[0, 0]`. `player.*` plays for
  `player.example` together with `*`. A rumble entry with outputs that return false makes the stage text
  `Rumble: strong 0.5, light 0.3 for 100 ms`; a cue the game lacks gives `Plays the sound hit`.
- [ ] **Step 2: Run** and see them fail.
- [ ] **Step 3: Implement** `feel-stage.ts`; the component runs on `requestAnimationFrame` for 1.5 s after each
  `replay` change, draws a 64 px square at the centre of a 2D canvas with offset, squash, flash and tint overlays and
  word keys as text, and lists the rumbles and cues it fired in an `aria-live="polite"` line.
- [ ] **Step 4: Run**; pass.
- [ ] **Step 5: Commit** `feat(editors): Feel's stage plays the chosen feel`.
